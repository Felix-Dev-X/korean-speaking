# 口语语法速查：韩国人嘴上的语法

> TOPIK 4 级的语法你都学过，但口语里**用哪些、怎么用、怎么缩**，课本讲得很少。这一页只讲口语。

---

## 1. 口语句尾（最重要）

| 句尾 | 核心意思 | 什么时候用 | 例句 |
|---|---|---|---|
| **-거든요** | 给出对方不知道的理由/背景 | 解释原因、铺垫话题 | 제가 요즘 좀 바쁘거든요. 我最近有点忙（所以……） |
| **-잖아요** | 提醒对方也知道的事 | "不是……嘛"、拉近距离 | 어제 비 왔잖아요. 昨天不是下雨了嘛 |
| **-더라고요** | 回述我亲身经历/观察到的 | 分享体验、感想 | 거기 생각보다 비싸더라고요. 那儿比想象的贵呢 |
| **-네요** | 当场发现、感叹 | 看到/尝到/听到时 | 이거 진짜 맛있네요. 这个真好吃啊 |
| **-는데요** | 委婉、留余地、轻微反驳 | 拒绝、表达不同意见、等对方反应 | 저는 괜찮은데요? 我觉得还好啊？ |
| **-(으)ㄹ걸요** | 不太确定的推测 | "应该是……吧" | 아마 문 닫았을걸요. 可能关门了吧 |
| **-나 봐요 / -(으)ㄴ가 봐요** | 根据线索推测 | 看到迹象后推测 | 밖에 비 오나 봐요. 外面好像在下雨 |
| **-죠** | 求确认 / 当然 | "……对吧？" | 내일 금요일이죠? 明天是周五对吧？ |
| **-(으)ㄹ래요?** | 问对方意愿 | 邀请、提议 | 같이 갈래요? 要一起去吗？ |
| **-(으)ㄹ게요** | 我来做（对对方的承诺） | 主动承担 | 제가 할게요. 我来做 |
| **-는 거예요** | 生动描述当时情况 | 讲故事 | 갑자기 문이 닫히는 거예요. 门突然就关了 |
| **-대요 / -래요** | 听说（转述） | 传话 | 내일 비 온대요. 听说明天下雨 |
| **-다면서요?** | 确认听来的消息 | "听说……是吗？" | 이사했다면서요? 听说你搬家了？ |
| **-던데요** | 我之前看到/感觉到的（带出下文） | 委婉分享观察 | 거기 맛있던데요? 那儿挺好吃的呀？ |
| **-아/어서요** | 只说理由，省略后半句 | 回答"为什么" | 갑자기 일이 생겨서요. 因为突然有事 |
| **-고요** | 补充信息 | "还有……" | 그리고 덜 달게 해 주시고요. 还有少甜一点 |

### 三秒判断法：-거든요 / -잖아요 / -더라고요

```
对方不知道 → -거든요     （我告诉你个原因）
对方也知道 → -잖아요     （你知道的嘛）
我亲身体验 → -더라고요   （我发现……）
```

## 2. 口语缩略（不会缩 = 像在念课文）

| 书面 | 口语 | | 书面 | 口语 |
|---|---|---|---|---|
| 그런데 | **근데** | | 이것은 / 그것은 / 저것은 | **이건 / 그건 / 저건** |
| 그러니까 | **그니까** | | 이것을 / 그것을 | **이걸 / 그걸** |
| 그러면 | **그럼** | | 이것이 / 그것이 | **이게 / 그게** |
| 그렇지요 | **그쵸 / 그치** | | 무엇을 | **뭘** |
| 무엇이 | **뭐가** | | 무엇 | **뭐** |
| 저는 / 나는 | **전 / 난** | | 저를 / 나를 | **절 / 날** |
| 제가 / 내가 | 제가 / 내가（不缩） | | 너는 / 너를 | **넌 / 널** |
| 저에게 / 나에게 | **저한테 / 나한테** | | 여기에 | **여기** |
| 하지 마세요 | **하지 마세요**（걱정하지 마세요 → **걱정 마세요**） | | 어디에 가요? | **어디 가요?** |
| ~하고 있어요 | ~하고 있어요 / **~하고 있어**（半语） | | 아니에요 | **아니에요 / 아냐**（半语） |
| ~해야 해요 | **~해야 돼요** | | 무엇 때문에 | **왜 / 뭐 때문에** |

口语里助词经常直接省略：**밥(을) 먹었어요? / 저(는) 학생이에요 / 어디(에) 가요?**

## 3. 填充词：争取思考时间

韩国人想词时不会沉默，而是说这些。**你也必须这样做。**

| 填充词 | 用法 | 例句 |
|---|---|---|
| **음… / 어…** | 最基本的"嗯……" | 음… 잘 모르겠어요. |
| **그냥** | "就、就是" | 그냥 집에서 쉬었어요. |
| **막** | 让描述更生动 | 막 사람이 엄청 많았어요. |
| **약간** | "有点、那种" | 약간 그런 느낌? |
| **좀** | 缓和语气（几乎每句都能加） | 이거 좀 도와주세요. |
| **뭐랄까** | "怎么说呢" | 뭐랄까, 좀 애매해요. |
| **뭐라고 해야 되지** | "该怎么说呢" | 뭐라고 해야 되지… 아, 맞다! |
| **그러니까** | "就是说" | 그러니까 제 말은… |
| **아무튼 / 어쨌든** | "总之" | 아무튼 재밌었어요. |
| **진짜 / 완전 / 엄청 / 너무** | 加强语气 | 완전 맛있어요. |

## 4. 敬语 ↔ 半语 秒切表

| 존댓말（해요体） | 반말 | 规则 |
|---|---|---|
| 네 / 아니요 | 응 / 아니 | |
| 저 / 제 / 저희 | 나 / 내 / 우리 | |
| ~이에요 / ~예요 | ~이야 / ~야 | 有收音 이야，无收音 야 |
| ~아요 / ~어요 / ~해요 | ~아 / ~어 / ~해 | 直接去掉 요 |
| ~(으)세요（命令） | ~아 / ~어 | 빨리 오세요 → 빨리 와 |
| ~(으)ㄹ까요? | ~자 / ~(으)ㄹ까? | 같이 먹을까요? → 같이 먹자 |
| ~(으)ㄹ래요? | ~(으)ㄹ래? | |
| ~죠? | ~지? | |
| ~거든요 / ~잖아요 / ~더라고요 | ~거든 / ~잖아 / ~더라 | |
| 안녕하세요 / 안녕히 가세요 | 안녕 / 잘 가 | |
| 감사해요 / 죄송해요 | 고마워 / 미안해 | |
| ~ 씨 | 이름 + 아/야（지민아, 민수야） | 有收音 아，无收音 야 |

**什么时候可以说半语？**
- 对方明确说了"말 놓을까요? / 말 편하게 해"之后
- 同龄好友、比你小且关系很熟的人
- **不能**：教授、前辈（除非对方允许）、店员、陌生人、长辈

## 5. 敬语进阶：对教授/上司/长辈

| 普通 | 敬语 | 例句 |
|---|---|---|
| 있다（在） | **계시다** | 교수님 연구실에 계세요? |
| 먹다 | **드시다 / 잡수시다** | 식사하셨어요? / 많이 드세요. |
| 자다 | **주무시다** | 안녕히 주무세요. |
| 말하다 | **말씀하시다**（对方说）/ **말씀드리다**（我说） | 제가 말씀드릴게요. |
| 묻다 | **여쭤보다**（我问） | 여쭤볼 게 있는데요. |
| 주다 | **드리다**（我给） | 자료 보내 드렸습니다. |
| 데리고 가다 | **모시고 가다** | 제가 모시고 갈게요. |
| 이름 / 나이 | **성함 / 연세** | 성함이 어떻게 되세요? |
| 집 / 밥 | **댁 / 진지** | 댁이 어디세요? |

## 6. 口语连接：把短句连成长句

TOPIK 4 级口语最常见的问题：**全是短句，没有连接**。用这些把句子"串起来"：

| 连接 | 意思 | 例句 |
|---|---|---|
| **-는데** | 铺垫背景 / 转折 | 어제 홍대 갔는데, 사람 엄청 많더라고요. |
| **-아/어서** | 因为…所以（自然原因） | 늦어서 죄송해요. |
| **-(으)니까** | 因为（强调理由，可接命令/建议） | 추우니까 따뜻하게 입어요. |
| **-고** | 然后、而且 | 밥 먹고 커피 마셨어요. |
| **-(으)면서** | 一边…一边 | 음악 들으면서 걸어요. |
| **-다가** | 做着做着（中断/转换） | 공부하다가 잠들었어요. |
| **-(으)ㄴ/는 김에** | 顺便 | 나온 김에 장 보고 갈게요. |
| **-아/어 보니까** | 试了之后发现 | 해 보니까 재밌더라고요. |
| **-(으)ㄹ 줄 알았는데** | 以为……结果 | 쉬울 줄 알았는데 어렵더라고요. |
| **-기는 한데** | ……是……，不过 | 비싸기는 한데 맛있어요. |

**练习**：把下面三句短句连成一句——
> 어제 친구를 만났어요. 카페에 갔어요. 사람이 많았어요.
> → 어제 친구 만나서 카페 갔는데, 사람이 엄청 많더라고요.

## 7. 语调（억양）

- **陈述** ↘：가요. （我去）
- **疑问** ↗：가요? （你去吗？）
- **命令**（短促）：가요! （去吧！）
- **邀请**（拖长、柔和）：같이 가요~ （一起去嘛～）
- **-는데요** 上扬 = 委婉反驳；下降 = 等对方回应
- **반말 疑问** 一定要上扬：밥 먹었어?↗

韩国人听懂你，一半靠语调。跟读时**先模仿语调，再管发音**。
