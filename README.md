每周 7 天：**第 1–5 天新课 → 第 6 天复习 + 现实任务 → 第 7 天周测 + 本周复盘**。

第 6 天的复习日固定安排**本周口语加练**：1 段朋友间半语长聊（角色扮演）+ 3 段听力理解（按难度从易到难排好）+ 3–4 组真实口语。20 周下来，20 段半语长聊、60 段听力、77 组真实口语正好全部练一遍。

### 怎么保证"练熟"

- **复习卡逐步撤掉提示**：① 跟读（看着韩语说）→ ② 回想（只看中文）→ ③ 实战（只看对方说了什么自己接；没有对话情境的句子限时 5 秒）。选「忘了」退回 ①。课程对话里你的台词也会进复习库，带着对方的上一句当情境。
- **旧课回炉**：每周复习日安排 1 周前、3 周前、8 周前的课对话，用**脱稿模式**再演一遍（轮到你时不显示中文）。
- **每课过关检验**：随机 5 句，只给中文或对方的话，80 分以上算过；过 4 句才算掌握这一课（课程列表里显示 🏅）。没过的句子自动进复习。
- **弱项自动进复习**：任何地方开口打分低于 60 分、接话选择选错、听力原文里点「没听懂」的句子，都会自动加入复习，今天就会再出现。

课程里 25 课的对话（朋友、同学、同事之间的）有**半语版**：在「② 情景对话」里切换「해요体 / 반말版」，同一段对话用两种语体各练一遍。

## 为什么 TOPIK 4 级还是说不出来？

1. **输入 ≠ 输出。** 你的语法和词汇是"认识"级别，不是"调用"级别。看得懂 -더라고요，不代表聊天时会冒出来。
2. **先中文、再翻译。** 你说话时在脑子里"造句"，所以慢、所以书面。韩国人说话是在"调用整句"。
3. **缺少口语专用零件。** 反应语（헐、그러니까요）、填充词（그냥、막、약간）、口语句尾（-거든요、-잖아요）、缩略（근데、뭘、난）——课本很少教，但每句话都在用。
4. **怕犯错，所以不开口。** 不开口就永远不会流利。

## 训练方法（这个项目为什么有效）

| 方法 | 做法 | 解决什么 |
|---|---|---|
| **句块（Chunk）** | 背整句，不背单词 | 不用临场造句，直接调用 |
| **影子跟读（Shadowing）** | 听一句、紧跟着说一句，模仿语调 | 发音、语调、语速 |
| **3 秒原则** | 看到提示 3 秒内开口 | 消灭"先想中文" |
| **角色扮演** | 两个角色都演 | 既能说，也能听懂对方的话 |
| **录音回听** | 每天独白录音并回听 | 发现自己听不见的问题 |
| **间隔复习** | 出声复习，按遗忘曲线排期 | 让句块变成长期记忆 |
| **AI + 真人实战** | 每周至少一次真人对话 | 把练过的东西用到真实世界 |
| **自言自语（실황 중계）** | 碎片时间用韩语描述自己在做什么 | 每天额外"免费"开口 20 分钟 |

### 每天的流程（60–90 分钟）

1. **复习**（10 分钟）：到期卡片，看中文出声说韩语
2. **句块跟读**（15 分钟）：每句至少跟读 3 遍，再遮住韩语自测
3. **情景对话**（15 分钟）：两个角色都演一遍
4. **句型快反**（15 分钟）：3 秒内开口
5. **独白录音**（10 分钟）：录音 → 回听 → 批改 → 把最差的一句重说 3 遍
6. **AI / 真人对话**（15 分钟）：把今天学的用出来

碎片时间：走路、洗澡、排队时用韩语自言自语——"지금 지하철 기다리고 있는데, 사람 진짜 많네. 아, 배고프다. 이따 뭐 먹지?"

### 训练铁律

1. **所有练习必须出声。** 默读 = 没练。
2. **3 秒原则。** 说错也比沉默强。
3. **不准先想中文再翻译。** 直接调用整句。
4. **每天开口 ≥ 30 分钟**，每周至少一次真人实战。
5. **独白必须录音并回听。** 听自己的录音很难受，但进步最快。
6. **卡住时用救场句**（뭐라고 해야 되지… / 그거 한국어로 뭐더라?），绝不沉默。

## 毕业标准：怎样算"能直接和韩国人日常对话"

20 周结束（第 140 天）时，用下面的清单自测。每一项都要能**不看任何提示、当场说出来**：

- [ ] 和初次见面的韩国人聊 15 分钟不冷场（自我介绍、提问、追问、找共同话题）
- [ ] 点餐、购物、问路、看病、办手机卡、寄快递、租房沟通，全程不需要翻译软件
- [ ] 听到消息能 1 秒内自然反应（진짜요? / 헐 / 어떡해 / 그러니까요）
- [ ] 日常说话自然使用 -거든요、-잖아요、-더라고요、-는데요、-나 봐요
- [ ] 能在敬语和半语之间正确切换（教授/前辈/朋友/店员）
- [ ] 能用 2 分钟讲一个自己的经历，有背景、经过、转折、结果
- [ ] 能表达并维护自己的观点（"그 말도 맞는데, 한편으로는…"）
- [ ] 能礼貌而坚定地投诉，也能吵架后道歉和好
- [ ] 能打韩语电话（预约、改约、确认信息、礼貌结束）
- [ ] 听不懂、想不起词时能用救场句把对话接下去
- [ ] 生日、婚礼、乔迁、节日、吊唁等场合说对话
- [ ] 能委婉地拒绝和提意见，听得懂别人的潜台词
- [ ] 能和朋友开玩笑、接梗，能用惯用语和俗语
- [ ] 能用 -습니다 体完成一场面试，能连续说 3 分钟不卡壳
- [ ] 朋友倾诉时能先共情、再安慰、再给建议
- [ ] 能自然使用推测、后悔、假设、让步和转述句型
- [ ] 韩国人常问的 200 个问题都能 5 秒内开口回答
- [ ] 价格、时间、日期、电话号码能脱口而出，不用先在脑子里换算
- [ ] 能把一个人、一个地方、一件东西、一个过程描述清楚
- [ ] 多人聊天时能插话、接话、把话题拉回来；能在聚餐上说祝酒词

## 项目结构

```
korean-speaking/
├── index.html                 ← 网站入口（跳转到 app/）
├── README.md                  ← 你正在看的文件
├── app/                       ← 练习 App（纯前端，无需安装）
│   ├── index.html
│   ├── style.css
│   ├── app.js                 ← 跟读/打分/角色扮演/快反/录音/复习/AI 陪练
│   └── data/                  ← 全部课程内容（修改这里即可扩充课程）
│       ├── week1-2.js … week19-20.js ← 20 周的第 1–4 课
│       ├── units-extra-1.js, -2.js   ← 每周第 5 课
│       ├── scenes-1.js … scenes-8.js ← 180 个情景对话
│       ├── phrasebank*.js            ← 功能句库
│       ├── shadowing*.js             ← 跟读短文
│       ├── qa*.js                    ← 百问百答
│       ├── styles.js, pairs.js       ← 语体转换、听辨练习
│       ├── replies.js, listening*.js ← 接话选择、听力理解
│       ├── spoken.js                 ← 真实口语
│       ├── pronunciation*.js         ← 发音规则
│       └── ai-scenarios.js           ← AI 陪练情景与提示词
├── lessons/                   ← 由数据自动生成的讲义（Markdown）
├── docs/
│   └── spoken-grammar.md      ← 口语语法速查
└── scripts/
    ├── load-data.mjs
    ├── check-data.mjs         ← 数据完整性检查
    ├── build-docs.mjs         ← 重新生成 lessons/
    └── build-artifact.mjs     ← 打包网页版 dist/korean-speaking.html
```

修改或新增课程内容后：

```bash
node scripts/check-data.mjs
```

```bash
node scripts/build-docs.mjs
```

```bash
node scripts/stamp-assets.mjs
```

（最后一条给网页文件加版本号，避免浏览器缓存把新旧文件混在一起用。）
