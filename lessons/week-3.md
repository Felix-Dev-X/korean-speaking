## 第 09 课　自然的自我介绍　<small>자연스러운 자기소개</small>

"안녕하세요, 저는 ~입니다. 만나서 반갑습니다"是课本。真人的自我介绍是聊天式的、会互相提问的。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 저는 중국에서 온 리웨이라고 해요. | 我是从中国来的李伟 | -(이)라고 해요 比 -입니다 更自然（名字换成你自己的） |
| 2 | 한국에 온 지 1년 좀 넘었어요. | 来韩国一年多一点了 | -(으)ㄴ 지 + 时间 + 되다/넘다 |
| 3 | 지금 대학원에서 컴퓨터공학 공부하고 있어요. | 我现在在研究生院学计算机 |  |
| 4 | 말하기는 아직 서툴러요. | 口语还不太熟练 |  |
| 5 | 고향이 어디세요? | 您老家是哪里？ |  |
| 6 | 한국 생활은 어때요? — 생각보다 재밌어요. | 在韩国生活怎么样？——比想象的有意思 | 一定会被问到，提前准备好答案 |
| 7 | 저희 나이도 비슷한 것 같은데 말 놓을까요? | 我们年纪差不多，要不说半语吧？ | 拉近关系的关键一句 |

## 第 10 课　爱好与日常闲聊　<small>취미와 일상 수다</small>

闲聊的核心：问对方 → 分享自己 → 追问细节 → 找到共同点 → 约下次。

| 2 | 요즘 뭐에 빠져 있어요? | 最近迷上了什么？ |  |
| 3 | 저는 요즘 러닝에 빠졌어요. | 我最近迷上了跑步 |  |
| 4 | 주말엔 그냥 집에서 넷플릭스 봐요. | 周末就在家看 Netflix |  |
| 5 | 그거 저도 봤어요! 완전 재밌죠? | 那个我也看了！超好看对吧？ |  |

## 第 11 课　约时间、改约、拒绝　<small>약속 잡기·바꾸기·거절</small>

韩国人很少直接说"不"。学会委婉拒绝和改约，才不会显得失礼。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 이번 주말에 시간 돼요? | 这周末有空吗？ |  |
| 2 | 토요일은 좀 애매하고, 일요일은 괜찮아요. | 周六不太好说，周日可以 |  |
| 3 | 몇 시쯤이 편해요? | 几点左右方便？ |  |
| 4 | 그럼 강남역에서 여섯 시에 볼까요? | 那六点在江南站见？ |  |
| 5 | 혹시 약속 좀 미뤄도 될까요? | 约会能往后推一下吗？ |  |
| 6 | 갑자기 일이 생겨서요. | 因为突然有点事 | -아/어서요：只说理由，后半句省略 |
| 7 | 미안해요, 그날은 선약이 있어서요. | 抱歉，那天已经有约了 |  |
| 8 | 다음에 꼭 같이 가요. | 下次一定一起去 |  |

- **하은**：그럼 일요일로 해요. 몇 시쯤이 편해요?  
  <sub>那就周日吧。几点左右方便？</sub>
- **나**：오후 두 시쯤 어때요? 오전엔 좀 늦잠 자고 싶어서요.

  <sub>知道了。那周日见！</sub>
- **나**：네, 일요일에 봐요!  
  <sub>好，周日见！</sub>

|---|---|

## 第 12 课　请求、道歉、感谢、被夸奖　<small>부탁·사과·감사·칭찬 받기</small>

韩国是重视礼节的社会。这些"关系润滑剂"说得好，别人会对你印象很好。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 혹시 이것 좀 도와주실 수 있어요? | 能帮我一下这个吗？ | 혹시 开头 = 更礼貌 |
| 2 | 바쁘신데 번거롭게 해 드려서 죄송해요. | 您这么忙还麻烦您，真抱歉 |  |
| 3 | 신경 써 주셔서 감사해요. | 谢谢您费心 |  |
| 4 | 덕분에 살았어요. | 多亏了你，得救了 |  |
| 5 | 별말씀을요. | 哪里的话（回应感谢） |  |
| 6 | 아니에요, 괜찮아요. | 没事，没关系 |  |
| 7 | 제가 실수했네요. 죄송합니다. | 是我弄错了，对不起 |  |
| 8 | 한국어 진짜 잘하시네요! — 아니에요, 아직 멀었어요. | 你韩语真好！——哪里，还差得远 | 被夸时一定要先谦虚 |
| 9 | 다음에 제가 밥 한번 살게요. | 下次我请你吃饭 |  |
| 10 | 앞으로 조심할게요. | 以后我会注意的 |  |

### ② 情景对话：向邻居阿姨请教垃圾分类

你扮演：**나**（两个角色都要练）

- **나**：안녕하세요. 혹시 이것 좀 도와주실 수 있어요? 분리수거를 어떻게 하는지 잘 몰라서요.  
  <sub>您好，能帮我一下吗？我不太懂垃圾怎么分类。</sub>
- **이웃 아주머니**：아, 그럼요. 이건 플라스틱이니까 이쪽에 넣으면 돼요.  
  <sub>啊，当然。这是塑料，放这边就行。</sub>
- **나**：아, 그렇구나. 음식물 쓰레기는요?  
  <sub>啊，原来如此。那厨余垃圾呢？</sub>
- **이웃 아주머니**：그건 전용 봉투에 담아서 저쪽 통에 버려야 돼요.  
  <sub>那个要装进专用袋子，扔到那边的桶里。</sub>
- **나**：아이고, 제가 지금까지 잘못 버렸네요. 죄송합니다.  
  <sub>哎呀，我之前一直扔错了。对不起。</sub>
- **이웃 아주머니**：괜찮아요. 처음엔 다들 헷갈려요. 한국어 진짜 잘하시네요!  
  <sub>没关系，一开始大家都搞不清。你韩语说得真好！</sub>
- **나**：아니에요, 아직 멀었어요. 신경 써 주셔서 정말 감사해요.  
  <sub>哪里，还差得远呢。真的谢谢您费心。</sub>
- **이웃 아주머니**：별말씀을요. 모르는 거 있으면 또 물어봐요.  
  <sub>哪里的话。有不懂的再问我。</sub>

### ③ 句型快反：关系润滑剂

> 请求 = 혹시 + -아/어 주실 수 있어요?；道歉要说原因；感谢要具体。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| 能借我用一下充电器吗？ | 혹시 충전기 좀 빌려주실 수 있어요? |
| 让你久等了，抱歉 | 오래 기다리게 해서 미안해요. |
| 谢谢你帮我这么多 | 이렇게 많이 도와줘서 고마워요. |
| 没关系，谁都会犯错 | 괜찮아요. 누구나 실수할 수 있죠. |
| 我不是故意的 | 일부러 그런 게 아니에요. |
| 能帮我拍张照片吗？ | 사진 좀 찍어 주실 수 있어요? |

### ④ 独白任务（录音 60 秒）

你不小心把同学/同事借你的资料弄丢了：真诚道歉 → 解释情况 → 提出补救方案 → 请求原谅 → 表示以后会注意。全程敬语。

可用表达：`정말 죄송한데요, 사실…`　`제가 ~하다가 그만 ~`　`제가 다시 ~해 드릴게요`　`앞으로 더 조심할게요`

## 第 19 天：现实任务（必须在真实世界完成）

- [ ] 参加一次语言交换（学校项目、HelloTalk、Meetup 都可以），用本周的自我介绍开场
- [ ] 主动约一个韩国同学/同事喝咖啡或吃饭，并敲定时间地点
- [ ] 被夸"한국어 잘하시네요"时，用正确的谦虚方式回应，并顺势把话题接下去

## 第 20 天：周测（每题录音，不看提示）

1. 90秒自然自我介绍（名字、来韩多久、为什么来、在做什么、一个爱好、一个对韩国的感受，最后抛一个问题）
2. 介绍你的一个爱好，并邀请对方下次一起
3. 约朋友周末见面 → 当天突然有事要改时间 → 见面时迟到道歉（三段连说）
4. 你借了同事的书不小心弄脏了：道歉 + 说明 + 补救方案

自评（各 1–5 分）：流利度 ___　准确度 ___　自然度 ___　反应速度 ___

## 第 21 天：自由对话日

至少 20 分钟不间断对话（真人优先，没有就用 AI 陪练），然后写复盘：最常卡壳的 3 句、最想记住的 3 个表达、下周要改的 1 个坏习惯。
