# 发音急救（18 条音变规则）

口语里"听不懂"和"说了对方听不懂"，一大半是音变问题。

## 连音（연음）

收音（받침）后面接元音开头的字（ㅇ），收音"滑"到下一个字上去读。这是最基本也最重要的规则。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 한국어 | [한구거] | 韩国语 |
| 음악 | [으막] | 音乐 |
| 옷이 | [오시] | 衣服（主格） |
| 맛있어요 | [마시써요] | 好吃 |
| 읽어요 | [일거요] | 读 |

例句：**한국어 발음이 어려워요.**　[한구거 바르미 어려워요]　（韩语发音很难）

## 鼻音化（비음화）

收音 ㄱ/ㄷ/ㅂ（及同类音）遇到 ㄴ/ㅁ 时，变成鼻音 ㅇ/ㄴ/ㅁ。"합니다"读[함니다]就是这个规则。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 합니다 | [함니다] | 做（正式） |
| 감사합니다 | [감사함니다] | 谢谢 |
| 작년 | [장년] | 去年 |
| 국물 | [궁물] | 汤汁 |
| 있는 | [인는] | 有的 |
| 먹는 | [멍는] | 吃的 |

例句：**지금 먹는 거 국물 있는 거예요?**　[지금 멍는 거 궁물 인는 거예요]　（现在吃的是带汤的吗？）

## 流音化（유음화）

ㄴ 和 ㄹ 相遇时，ㄴ 变成 ㄹ，读成[ㄹㄹ]。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 연락 | [열락] | 联系 |
| 신라 | [실라] | 新罗 |
| 설날 | [설랄] | 春节 |
| 관리 | [괄리] | 管理 |
| 편리해요 | [펼리해요] | 方便 |

例句：**설날에 연락할게요.**　[설라레 열락할께요]　（春节时联系你）

## 紧音化（경음화）

收音 ㄱ/ㄷ/ㅂ 后面的 ㄱ/ㄷ/ㅂ/ㅅ/ㅈ 变紧音；"-(으)ㄹ"后面的 ㄱ/ㄷ/ㅂ/ㅅ/ㅈ 也变紧音（할 거예요[할 꺼예요]）。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 학교 | [학꾜] | 学校 |
| 식당 | [식땅] | 食堂、餐厅 |
| 갈 거예요 | [갈 꺼예요] | 会去的 |
| 할 수 있어요 | [할 쑤 이써요] | 能做 |
| 할게요 | [할께요] | 我来做 |
| 문법 | [문뻡] | 语法 |

例句：**내일 학교 식당에서 먹을 거예요.**　[내일 학꾜 식땅에서 머글 꺼예요]　（明天要在学校食堂吃）

## 送气化（격음화）

ㅎ 和 ㄱ/ㄷ/ㅂ/ㅈ 相遇，合并成送气音 ㅋ/ㅌ/ㅍ/ㅊ。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 좋다 | [조타] | 好 |
| 축하해요 | [추카해요] | 恭喜 |
| 많지 | [만치] | 多吧 |
| 입학 | [이팍] | 入学 |
| 어떡해 | [어떠캐] | 怎么办 |
| 그렇게 | [그러케] | 那样 |

例句：**입학 축하해요! 어떻게 그렇게 잘했어요?**　[이팍 추카해요 어떠케 그러케 잘해써요]　（恭喜入学！怎么做得那么好？）

## ㅎ 弱化 / 脱落

收音 ㅎ 后面接元音时 ㅎ 不发音；ㄴ/ㄹ/ㅁ/ㅇ 和元音之间的 ㅎ 在口语里也常常被弱化。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 좋아요 | [조아요] | 好 |
| 많이 | [마니] | 很多 |
| 괜찮아요 | [괜차나요] | 没关系 |
| 싫어요 | [시러요] | 不要 |
| 결혼 | [겨론]（口语） | 结婚 |
| 전화 | [저놔]（口语） | 电话 |

例句：**괜찮아요, 많이 좋아졌어요.**　[괜차나요 마니 조아져써요]　（没关系，好多了）

## 腭化（구개음화）

收音 ㄷ/ㅌ 遇到 이 时，变成 ㅈ/ㅊ。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 같이 | [가치] | 一起 |
| 굳이 | [구지] | 非要 |
| 해돋이 | [해도지] | 日出 |
| 밭이 | [바치] | 田地（主格） |

例句：**굳이 같이 안 가도 돼요.**　[구지 가치 안 가도 돼요]　（没必要非一起去）

## 双收音（겹받침）

双收音单独读时只读一个；后面接元音时，第二个音连到下一个字。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 읽다 / 읽어요 | [익따] / [일거요] | 读 |
| 앉다 / 앉으세요 | [안따] / [안즈세요] | 坐 |
| 없다 / 없어요 | [업따] / [업써요] | 没有 |
| 넓다 / 넓어요 | [널따] / [널버요] | 宽 |
| 값 / 값이 | [갑] / [갑씨] | 价格 |

例句：**여기 앉으세요. 자리 없어요?**　[여기 안즈세요 자리 업써요]　（请坐这儿。没有座位吗？）

## ㄴ 添加（ㄴ첨가）

复合词或词组中，前面有收音、后面是 이/야/여/요/유 时，中间加一个 ㄴ（如果前面收音是 ㄹ 则变成 ㄹ）。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 무슨 일 | [무슨 닐] | 什么事 |
| 할 일 | [할 릴] | 要做的事 |
| 서울역 | [서울력] | 首尔站 |
| 한여름 | [한녀름] | 盛夏 |
| 볼일 | [볼릴] | 要办的事 |

例句：**무슨 일 있어요? 할 일이 많아요?**　[무슨 닐 이써요 할 리리 마나요]　（有什么事吗？要做的事很多吗？）

## 의 的三种读法

词首读[의]；词中或辅音后读[이]；作属格助词"的"时读[에]。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 의사 | [의사] | 医生 |
| 회의 | [회이] | 会议 |
| 희망 | [히망] | 希望 |
| 우리의 꿈 | [우리에 꿈] | 我们的梦想 |

例句：**회의에서 의사 선생님의 의견을 들었어요.**　[회이에서 의사 선생니메 의겨늘 드러써요]　（在会上听了医生的意见）

## 口语中的"偷懒"发音

不标准但韩国人天天这么说，要听得懂：-고 → [구]，-도 → [두]，그런데 → 근데，그러니까 → 그니까，뭐라고 → 뭐라구。自己说时用标准音就好，但要能听懂。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 그리고 | [그리구] | 然后 |
| 나도 | [나두] | 我也 |
| 하고 있어 | [하구 이써] | 正在做 |
| 그러니까 | [그니까] | 所以说 |
| 뭐라고? | [뭐라구?] | 你说什么？ |

例句：**나도 지금 밥 먹고 있어.**　[나두 지금 밥 먹꾸 이써]　（我也正在吃饭）

## 语调决定意思（억양）

해요体同一个句子，语调不同意思完全不同。陈述↘、疑问↗、命令（短促有力）、邀请（拖长柔和）。韩国人听懂你，一半靠语调。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 가요.↘ | [陈述] 我去 | 去 |
| 가요?↗ | [疑问] 你去吗？ | 去 |
| 가요! | [命令] 去吧！ | 去 |
| 같이 가요~ | [邀请] 一起去嘛～ | 去 |
| 진짜?↗ / 진짜.↘ | 真的？（疑问）／真的。（肯定） | 真的 |

例句：**밥 먹었어요? 네, 먹었어요. 같이 먹어요~**　[疑问↗] [陈述↘] [邀请~]　（吃了吗？嗯，吃了。一起吃嘛～）

## 易混元音：어/오、으/우、애/에

中国人最容易混的元音。어 嘴巴张开、不圆唇；오 嘴唇收圆往前。으 嘴角往两边拉、不圆唇；우 嘴唇圆而突出。애/에 在现代首尔话里几乎同音，靠上下文区分。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 거기 / 고기 | [거기] / [고기] | 那里／肉 |
| 어서 / 오서 | [어서] 快 / 오다的变形 | 快（请） |
| 그림 / 구림 | [그림] / [구림] | 画／（口语）差劲 |
| 쓰다 / 쑤다 | [쓰다] / [쑤다] | 写、苦／熬（粥） |
| 개 / 게 | [개] / [게] | 狗／螃蟹 |

例句：**거기서 고기 먹고 그림 그렸어요.**　[거기서 고기 먹꼬 그림 그려써요]　（在那里吃了肉、画了画）

## 平音、紧音、送气音

韩语辅音分三组：平音（ㄱㄷㅂㅈㅅ）轻、不送气；紧音（ㄲㄸㅃㅉㅆ）喉咙绷紧、短促有力；送气音（ㅋㅌㅍㅊ）带明显气流。读错会变成完全不同的词。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 가다 / 까다 / 카드 | [가다] / [까다] / [카드] | 去／剥／卡 |
| 달 / 딸 / 탈 | [달] / [딸] / [탈] | 月亮／女儿／面具 |
| 불 / 뿔 / 풀 | [불] / [뿔] / [풀] | 火／角／草 |
| 자다 / 짜다 / 차다 | [자다] / [짜다] / [차다] | 睡／咸／踢、冷 |
| 사다 / 싸다 | [사다] / [싸다] | 买／便宜 |

例句：**이거 싸요? 사고 싶어요.**　[이거 싸요 사고 시퍼요]　（这个便宜吗？我想买）

## 收音辨别：ㄴ/ㅇ/ㅁ、ㄱ/ㄷ/ㅂ

中国南方人常混 ㄴ 和 ㅇ。ㄴ 舌尖顶上齿龈；ㅇ 舌根抬起、像"昂"的尾音；ㅁ 闭上嘴唇。ㄱ/ㄷ/ㅂ 收音只做口型、不爆破出声。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 반 / 방 / 밤 | [반] / [방] / [밤] | 一半、班／房间／夜、栗子 |
| 산 / 상 / 삼 | [산] / [상] / [삼] | 山／奖、桌子／三 |
| 강 / 감 | [강] / [감] | 江／柿子 |
| 각 / 갇 / 갑 | [각] / [갇] / [갑] | 角／被关（갇다）／甲 |
| 입 / 잎 | [입] / [입] | 嘴／叶子（收音同音） |

例句：**방에서 반만 먹고 밤에 산에 갔어요.**　[방에서 반만 먹꼬 바메 사네 가써요]　（在房间里只吃了一半，晚上去了山上）

## 数字的读法

固有数词（하나, 둘…）用于个数、年龄、小时；汉字数词（일, 이…）用于钱、日期、分钟、电话、楼层。注意特殊读法：6월[유월]、10월[시월]、16[심뉵]、전화번호的"-"读作[에]。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 세 시 삼십 분 | [세 시 삼십 뿐] | 三点三十分 |
| 유월 / 시월 | [유월] / [시월] | 六月／十月（不是육월、십월） |
| 열여섯 / 십육 | [열려섣] / [심뉵] | 十六（固有词／汉字词） |
| 010-1234-5678 | [공일공 에 일이삼사 에 오육칠팔] | 电话号码 |
| 스물다섯 살 | [스물다섣 쌀] | 二十五岁 |

例句：**유월 십육 일 세 시에 만나요.**　[유월 심뉴 길 세 시에 만나요]　（六月十六日三点见）

## 外来语的韩式发音

外来语要按韩语发音说，不要按英语说，否则韩国人反而听不懂。辅音后常加"으"，f 变 ㅍ，v 变 ㅂ，z 变 ㅈ。口语里一些词还会变紧音。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 커피 | [커피]（不是 coffee） | 咖啡 |
| 아이스 아메리카노 | [아이스 아메리카노] | 冰美式 |
| 버스 / 카페 | [버스]（口语常读[뻐스]）/ [카페]（口语[까페]） | 公交／咖啡店 |
| 패스트푸드 | [패스트푸드] | 快餐（fast food） |
| 비타민 | [비타민] | 维生素（vitamin） |

例句：**카페에서 아이스 아메리카노랑 케이크 시켰어요.**　[카페에서 아이스 아메리카노랑 케이크 시켜써요]　（在咖啡店点了冰美式和蛋糕）

## 长句的节奏：按意群停顿

韩国人说长句时不会一个字一个字读，而是按"意群"（主语/状语/宾语+谓语）连起来读，在意群之间短暂停顿，句尾语调下降或上扬。按意群跟读，听起来会自然很多。斜线 / 表示停顿。

| 拼写 | 实际发音 | 意思 |
|---|---|---|
| 어제 친구랑 / 홍대에 가서 | 两个意群 | 昨天和朋友去了弘大 |
| 맛있는 거 먹고 / 쇼핑도 했어요 | 两个意群 | 吃了好吃的，还逛了街 |
| 제가 말씀드린 그 자료는 / 메일로 보내 드렸습니다 | 主语长时在主语后停 | 我说的那个资料已经发邮件给您了 |
| 비가 와서 / 길이 막혀서 / 좀 늦을 것 같아요 | 三个原因/结果意群 | 因为下雨堵车，可能会晚一点 |

例句：**어제 친구랑 홍대에 가서 맛있는 거 먹고 쇼핑도 했어요.**　[어제 친구랑 / 홍대에 가서 / 마신는 거 먹꼬 / 쇼핑도 해써요]　（昨天和朋友去弘大，吃了好吃的还逛了街）
