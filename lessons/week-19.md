## 第 73 课　插话、接话与拉回话题　<small>말 끼어들기와 이어받기</small>

多人聊天时不会插话，就永远只能听。学会礼貌地打断、接住别人的话、补充、以及把话题拉回来。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 잠깐만요, 저도 한마디 해도 될까요? | 等一下，我也可以说一句吗？ |  |
| 2 | 말씀 중에 죄송한데요… | 不好意思打断您…… |  |
| 3 | 아, 그 얘기 나와서 말인데요… | 啊，既然说到这个…… |  |
| 4 | 맞아요, 거기에 덧붙이자면… | 对，补充一点的话…… |  |
| 5 | 방금 하신 말씀에 동의하는데, 하나만 더 말하면… | 同意您刚才说的，再说一点的话…… |  |
| 6 | 아, 미안해요. 먼저 말씀하세요. | 啊，抱歉，您先说 |  |
| 7 | 아까 하던 얘기로 돌아가면요… | 回到刚才说的话题…… |  |
| 8 | 어디까지 얘기했죠? | 刚才说到哪儿了？ |  |
| 9 | 그래서요? 계속 얘기해 주세요. | 然后呢？请继续说 |  |
| 10 | 제 말은 그게 아니라요… | 我的意思不是那样…… |  |

### ② 情景对话：研究室四人讨论聚餐地点

你扮演：**나**（两个角色都要练）

- **선배 지훈**：이번 회식은 고깃집으로 하자. 학교 앞에 새로 생긴 데가 있는데…  
  <sub>这次聚餐去烤肉店吧。学校门口新开了一家……</sub>
- **동기 서연**：아, 거기 저번에 가 봤는데 좀 비싸더라고요.  
  <sub>啊，那家我上次去过，有点贵。</sub>
- **나**：잠깐만요, 저도 한마디 해도 될까요? 고기도 좋은데, 이번엔 중식은 어때요? 제가 맛집 알거든요.  
  <sub>等一下，我也可以说一句吗？烤肉也不错，这次吃中餐怎么样？我知道一家好吃的。</sub>
- **선배 지훈**：오, 중식? 근데 서연 씨가 매운 걸 잘 못 먹잖아.  
  <sub>哦，中餐？不过瑞妍不太能吃辣嘛。</sub>
- **나**：맞아요. 거기에 덧붙이자면, 거기는 안 매운 메뉴가 더 많아요. 꿔바로우랑 딤섬 같은 거요.  
  <sub>对。补充一点，那家不辣的菜更多。比如锅包肉和点心。</sub>
- **동기 서연**：아, 그럼 좋아요! 근데 아까 선배가 말씀하시던 고깃집은요?  
  <sub>啊，那好啊！不过刚才前辈说的烤肉店呢？</sub>
- **선배 지훈**：아, 아까 하던 얘기로 돌아가면, 고깃집은 다음 달 생일 파티 때 가자.  
  <sub>啊，回到刚才的话题，烤肉店下个月生日派对的时候去吧。</sub>
- **나**：좋아요! 그럼 이번엔 중식, 다음 달엔 고기. 제가 예약할게요.  
  <sub>好啊！那这次中餐，下个月烤肉。我来预约。</sub>

### ③ 句型快反：插话 → 接话 → 补充 → 纠正 → 拉回

> 插话时先道歉（죄송한데요 / 잠깐만요），接话时先肯定（맞아요 / 그 말 듣고 생각났는데），拉回时用"아까"。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| （插话）不好意思打断一下 | 말씀 중에 죄송한데요. |
| （接话）听你这么说我想起来了 | 그 얘기 들으니까 생각났는데요. |
| （补充）还有一点 | 그리고 하나 더 있는데요. |
| （纠正误会）我不是那个意思 | 제 말은 그런 뜻이 아니라요. |
| （让对方先说）啊，你先说吧 | 아, 먼저 말해. |
| （拉回话题）我们刚才说到哪了？ | 아까 어디까지 얘기했죠? |

### ④ 独白任务（录音 2 分钟）

模拟三人讨论（周末去哪玩）：你至少要插话 1 次、接话补充 1 次、纠正一次误会、最后把被岔开的话题拉回来并做出决定。一人分饰三角。

可用表达：`잠깐만요, 저도 한마디 해도 될까요?`　`거기에 덧붙이자면`　`제 말은 그게 아니라요`　`아까 하던 얘기로 돌아가면`　`그럼 이렇게 하죠`

## 第 74 课　强调与夸张　<small>강조와 과장</small>

韩国人讲故事、吐槽、夸人时很爱夸张：죽겠다、미쳤다、장난 아니다……学会这些，你的韩语就有了"情绪"。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 배고파 죽겠어요. | 饿死了 |  |
| 2 | 진짜 장난 아니었어요. | 真不是闹着玩的（太夸张了） |  |
| 3 | 그 집 떡볶이 미쳤어요. | 那家炒年糕绝了 |  |
| 4 | 사람이 너무 많아서 숨도 못 쉴 정도였어요. | 人多到连气都喘不过来 |  |
| 5 | 백 번 말해도 안 들어요. | 说一百遍都不听 |  |
| 6 | 평생 잊지 못할 거예요. | 一辈子都忘不了 |  |
| 7 | 세상에서 제일 맛있어요. | 世界上最好吃 |  |
| 8 | 눈물이 날 정도로 웃었어요. | 笑到流眼泪 |  |
| 9 | 완전 대박 사건이에요. | 超级大事件 |  |
| 10 | 말도 안 되게 비싸요. | 贵得离谱 |  |

### ② 情景对话：跟朋友吐槽昨天的离谱经历

你扮演：**나**（两个角色都要练）

- **나**：야, 어제 진짜 대박 사건 있었어.  
  <sub>喂，昨天发生了一件超离谱的事。</sub>
- **친구 민지**：뭔데? 빨리 말해 봐.  
  <sub>什么事？快说。</sub>
- **나**：퇴근길에 지하철이 고장 나서 한 시간 동안 갇혀 있었어. 사람이 너무 많아서 숨도 못 쉴 정도였어.  
  <sub>下班路上地铁坏了，被困了一个小时。人多到连气都喘不过来。</sub>
- **친구 민지**：헐, 진짜? 완전 최악이다.  
  <sub>天哪，真的？最惨了。</sub>
- **나**：그치? 배고파 죽겠는데 핸드폰 배터리까지 나갔어.  
  <sub>对吧？饿得要死，手机还没电了。</sub>
- **친구 민지**：아이고, 그래서 어떻게 했어?  
  <sub>哎哟，那怎么办的？</sub>
- **나**：옆에 계시던 할머니가 사탕을 주셨는데, 그게 세상에서 제일 맛있었어. 하하.  
  <sub>旁边的奶奶给了我颗糖，那是世界上最好吃的糖。哈哈。</sub>
- **친구 민지**：하하, 눈물 날 정도로 웃기다. 평생 잊지 못할 하루였겠네.  
  <sub>哈哈，笑出眼泪了。那一定是一辈子忘不了的一天。</sub>

### ③ 句型快反：强调程度：-아/어 죽겠다 / -(으)ㄹ 정도로 / 장난 아니다 / 세상에서 제일 / 말도 안 되게

> 夸张只用在轻松场合和熟人之间。对长辈或正式场合，改用"정말 / 너무 / 굉장히"。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| 累死了 | 피곤해 죽겠어. |
| 好吃到想哭 | 울고 싶을 정도로 맛있어요. |
| 今天热得不得了 | 오늘 더위 장난 아니에요. |
| 这是我这辈子看过最好看的电影 | 제 인생 최고의 영화예요. |
| 贵得离谱 | 말도 안 되게 비싸요. |
| （对长辈，改成正式的强调）真的非常好吃 | 정말 굉장히 맛있어요. |

### ④ 独白任务（录音 2 分钟）

用至少 6 种强调/夸张表达，讲一件你经历过的"超级离谱/超级好笑/超级感动"的事。然后用正式的强调方式（정말、굉장히、매우）把同一件事讲给长辈听，体会语气差别。

可用表达：`완전 대박 사건`　`~ 죽겠다`　`~ 정도로`　`장난 아니었어`　`세상에서 제일 ~`　`（正式）정말 / 굉장히 / 매우`

## 第 75 课　反话、玩笑式吐槽与言外之意　<small>반어와 말속의 뜻</small>

"잘한다~"可能是在骂你，"알아서 해"可能是在生气。听懂反话和言外之意，才不会在人际关系里踩雷。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 참 잘했다~ | 做得真"好"啊（反话：你搞砸了） |  |
| 2 | 잘 논다~ | 玩得真"好"（反话：太过分了） |  |
| 3 | 알아서 해. | 你自己看着办（常常是在生气） |  |
| 4 | 됐어, 괜찮아. | 算了，没事（可能其实很不高兴） |  |
| 5 | 그래, 너 잘났다. | 是是是，你最厉害（讽刺） |  |
| 6 | 아주 신났네, 신났어. | 真是高兴坏了啊（讽刺对方得意忘形） |  |
| 7 | 진짜 고맙다, 고마워. | 真是"谢谢"你啊（反话） |  |
| 8 | 시간 되면 한번 보자. | 有空见一面吧（客套，未必真约） |  |
| 9 | 다음에 밥 한번 먹어요. | 下次吃个饭吧（客套话） |  |
| 10 | 혹시 지금 화났어? | 你现在是生气了吗？（确认言外之意） |  |

### ② 情景对话：你忘了和女朋友的约定

你扮演：**나**（两个角色都要练）

- **여자친구 하은**：어제 내 전화 왜 안 받았어?  
  <sub>昨天为什么不接我电话？</sub>
- **나**：아, 미안. 친구들이랑 축구 보느라 못 들었어.  
  <sub>啊，抱歉。和朋友看球没听到。</sub>
- **여자친구 하은**：아주 신났네, 신났어. 우리 어제 저녁 먹기로 한 거 기억 안 나?  
  <sub>真是高兴坏了啊。不记得我们昨天约好吃晚饭了？</sub>
- **나**：헉… 진짜 미안해. 완전히 까먹었어.  
  <sub>啊……真的对不起。我完全忘了。</sub>
- **여자친구 하은**：됐어, 괜찮아. 알아서 해.  
  <sub>算了，没事。你自己看着办。</sub>
- **나**：…혹시 지금 많이 화났어? 괜찮다는 게 진짜 괜찮은 거 아니지?  
  <sub>……你现在是不是很生气？你说没事，其实不是真的没事吧？</sub>
- **여자친구 하은**：…응. 좀 서운했어.  
  <sub>……嗯。有点失落。</sub>
- **나**：내가 잘못했어. 오늘 저녁에 네가 가고 싶었던 그 식당 가자. 내가 예약할게.  
  <sub>是我错了。今晚去你一直想去的那家餐厅吧。我来预约。</sub>

### ③ 句型快反：听懂言外之意 → 确认 → 回应

> 听到可能是反话的话时，不要按字面回应。先用"혹시 ~?"确认对方的真实情绪，再道歉或解释。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| （朋友冷冷地说"참 잘했다~"）→ 确认并道歉 | 혹시 나 때문에 화났어? 미안해. |
| （对方说"됐어, 괜찮아"但语气很冷）→ 确认 | 괜찮다는 게 진짜 괜찮은 거 아니지? |
| （同事说"다음에 밥 한번 먹어요"）→ 礼貌回应客套 | 네, 좋아요. 다음에 꼭 먹어요. |
| （妈妈说"알아서 해"）→ 主动认错 | 엄마, 제가 잘못했어요. 그렇게 안 할게요. |
| （朋友得意时）你真是高兴坏了啊（开玩笑） | 아주 신났네, 신났어. 하하. |
| （想真约饭时）不是客套，这周五怎么样？ | 빈말 아니고, 이번 주 금요일 어때요? |

### ④ 独白任务（录音 2 分钟）

模拟一段对话：你做了一件让朋友/恋人不高兴的事，对方用了 2–3 句反话。你要先听出真实意思、用"혹시 ~?"确认、真诚道歉、最后提出补偿方案。再解释一下"다음에 밥 한번 먹어요"什么时候是客套、什么时候是真约。

可用表达：`혹시 지금 화났어?`　`괜찮다는 게 진짜 괜찮은 거 아니지?`　`내가 잘못했어`　`그 대신 ~`　`빈말 아니고 ~`

## 第 76 课　致辞、祝酒词与小型发言　<small>인사말·건배사·발표</small>

入职、送别、婚礼、聚餐、发表会——在韩国总有被要求"说两句"的时候。准备好几套万能结构，随时能站起来说。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 바쁘신 와중에 이렇게 와 주셔서 감사합니다. | 感谢大家百忙之中来到这里 |  |
| 2 | 간단하게 한 말씀 드리겠습니다. | 我简单说几句 |  |
| 3 | 이 자리를 빌려 감사의 말씀을 전하고 싶습니다. | 想借这个机会表达感谢 |  |
| 4 | 부족한 저를 많이 도와주셔서 감사합니다. | 感谢大家对不成熟的我的帮助 |  |
| 5 | 앞으로도 잘 부탁드리겠습니다. | 今后也请多多关照 |  |
| 6 | 제가 "위하여"라고 하면 다 같이 "위하여"라고 외쳐 주세요. | 我说"为了"，大家一起喊"为了" |  |
| 7 | 우리 팀의 건강과 행복을 위하여! | 为了我们团队的健康和幸福！ |  |
| 8 | 오늘 발표할 내용은 크게 세 가지입니다. | 今天要发表的内容主要有三点 |  |
| 9 | 마지막으로 한 가지만 더 말씀드리면… | 最后再说一点…… |  |
| 10 | 들어 주셔서 감사합니다. 질문 있으시면 편하게 해 주세요. | 谢谢大家聆听。有问题请随时提出 |  |

### ② 情景对话：研究室年终聚餐，教授让你说祝酒词

- **김 교수님**：자, 올해 마지막 회식인데 리웨이 씨가 건배사 한번 해 볼까요?  
  <sub>来，今年最后一次聚餐，李伟来说个祝酒词吧？</sub>
- **나**：아, 네! 그럼 간단하게 한 말씀 드리겠습니다.  
  <sub>啊，好的！那我简单说几句。</sub>
- **나**：올해 처음 연구실에 왔을 때는 한국어도 서툴고 모르는 것도 많았는데, 다들 정말 많이 도와주셨어요.  
  <sub>今年刚来研究室时，韩语不熟练，不懂的也很多，大家真的帮了我很多。</sub>
- **나**：특히 교수님께서 늘 격려해 주셔서 끝까지 버틸 수 있었습니다. 이 자리를 빌려 감사의 말씀을 드립니다.  
  <sub>特别是教授一直鼓励我，我才坚持到了最后。借这个机会向您表示感谢。</sub>
