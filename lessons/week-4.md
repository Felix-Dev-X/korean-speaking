## 第 13 课　半语基础：秒切朋友模式　<small>반말 전환</small>

和同龄朋友"말을 놓다"之后，还一直用敬语反而显得疏远。半语是真正交朋友的门票。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 밥 먹었어? | 吃饭了吗？（≈你好） |  |
| 2 | 뭐 해? / 어디야? | 在干嘛？／在哪儿？ |  |
| 3 | 나 지금 가는 중. | 我正在路上 |  |
| 4 | 응, 알겠어. | 嗯，知道了 |  |
| 5 | 아니, 괜찮아. | 不用，没事 |  |
| 6 | 진짜? 왜? | 真的？为什么？ |  |
| 7 | 나도! / 나도 그래. | 我也是！ |  |
| 8 | 그럼 이따 봐. | 那待会儿见 |  |
| 9 | 잘 자, 내일 봐. | 晚安，明天见 |  |
| 10 | 야, 너 이거 봤어? | 喂，你看到这个了吗？ | "야"只对很熟的朋友/晚辈用 |

### ③ 句型快反：敬语 → 半语 秒切

> 이에요/예요 → (이)야；저/제 → 나/내；네 → 응；아니요 → 아니；-(으)세요 → -아/어；-(으)ㄹ까요? → -자 / -(으)ㄹ까?

| 提示（5秒内开口） | 参考答案 |
|---|---|
| 지금 어디예요? | 지금 어디야? |
| 저도 가고 싶어요. | 나도 가고 싶어. |
| 이거 제 거예요. | 이거 내 거야. |
| 네, 알겠어요. 내일 봐요. | 응, 알겠어. 내일 봐. |
| 빨리 오세요! | 빨리 와! |
| 같이 먹을까요? | 같이 먹자! |

### ④ 独白任务（录音 60 秒）

用半语给好朋友发一段语音：约他/她这周末出去玩，说明去哪、做什么、几点见，再吐槽一下你这周有多累。

可用表达：`야, 이번 주말에 뭐 해?`　`우리 ~ 가자`　`나 이번 주 진짜 너무 힘들었어`　`~ 때문에 죽는 줄 알았어`

## 第 14 课　情绪表达　<small>감정 표현</small>

只会说"좋아요/싫어요"的人永远聊不深。学会表达烦躁、心动、失落、委屈、感动。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 아, 진짜 짜증 나. | 啊，烦死了 |  |
| 2 | 완전 설렌다. | 超心动／好期待 |  |
| 3 | 좀 서운해. | 有点失落／心里不是滋味 | 서운하다：对亲近的人期待落空时的失落 |
| 4 | 속상해 죽겠어. | 难受死了／心里憋屈 |  |
| 5 | 와, 소름 돋았어. | 哇，起鸡皮疙瘩了 | 惊讶、感动、恐怖都能用 |
| 6 | 긴장돼서 미치겠어. | 紧张得要疯了 |  |
| 7 | 이제 좀 마음이 편해졌어. | 现在心里舒坦多了 |  |
| 8 | 어이가 없네. | 真无语／太离谱了 |  |
| 9 | 신경 쓰지 마. | 别在意 |  |
| 10 | 기분 전환 좀 하자. | 换换心情吧 |  |

### ② 情景对话：你跟朋友宥娜吐槽小组作业

你扮演：**나**（两个角色都要练）

- **나**：아, 진짜 짜증 나.  
  <sub>啊，烦死了。</sub>
- **친구 유나**：왜? 무슨 일 있어?  
  <sub>怎么了？出什么事了？</sub>
- **나**：팀플 조원 한 명이 또 연락이 안 돼. 발표가 내일인데.  
  <sub>小组作业有个组员又联系不上了。明天就要发表了。</sub>
- **친구 유나**：헐, 어이가 없네. 너 혼자 다 하는 거야?  
  <sub>天哪，真无语。你一个人全做吗？</sub>
- **나**：응… 진짜 속상해 죽겠어.  
  <sub>嗯……真的憋屈死了。</sub>
- **친구 유나**：아이고, 고생이 많다. 일단 교수님한테 말씀드려 봐.  
  <sub>哎呀，辛苦你了。先跟教授说一下吧。</sub>
- **나**：그래야겠다. 너한테 얘기하니까 좀 마음이 편해졌어.  
  <sub>应该这样。跟你说完心里舒服多了。</sub>
- **친구 유나**：끝나고 맛있는 거 먹으면서 기분 전환 좀 하자.  
  <sub>结束后吃点好吃的换换心情吧。</sub>

### ③ 句型快反：情绪 + 原因

> 情绪不要只说一个词，要带原因：原因 + -아/어서 / -(이)라서 + 情绪。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| 考试前，好紧张 | 시험 전이라 너무 긴장돼. |
| 你忘了我生日，有点失落 | 내 생일 까먹어서 좀 서운해. |
| 那部电影结局让我起鸡皮疙瘩 | 그 영화 결말 보고 소름 돋았어. |
| 明天去旅行，超期待 | 내일 여행 가는데 완전 설렌다. |
| 别在意那种人说的话 | 그런 사람 말은 신경 쓰지 마. |
| 真的气死我了 | 진짜 열받아. |

## 第 15 课　新词与缩略语　<small>신조어·줄임말</small>

新词用对 = 瞬间拉近距离。但对长辈、正式场合不要用。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 인정, 인정. | 认同认同／确实 | 比"맞아"更年轻 |
| 2 | 실화야? | 真的假的？（字面：是真事吗） |  |
| 3 | 나 오늘 완전 멘붕이야. | 我今天彻底崩溃了 | 멘붕 = 멘탈 붕괴 |
| 4 | 이거 완전 꿀팁이다. | 这真是超实用的小窍门 |  |
| 5 | 그 영화 꿀잼이야. / 노잼이야. | 那电影超好看／超无聊 |  |
| 6 | 라면엔 김치, 이건 국룰이지. | 泡面配泡菜，这是铁律 | 국룰 = 国民规则 |
| 7 | 갑자기 분위기 싸해졌어. | 气氛突然冷下来了 | 缩略：갑분싸 |
| 8 | 아, 이건 TMI인데… | 啊，这个是题外话…… |  |
| 9 | 어제 혼밥했어. | 昨天一个人吃的饭 |  |
| 10 | 일하다가 갑자기 현타 왔어. | 工作时突然觉得一切都没意义了 | 현타 = 현실 자각 타임 |

### ② 情景对话：跟朋友珉宰聊昨天的综艺

你扮演：**나**（两个角色都要练）

- **친구 민재**：야, 너 어제 그 예능 봤어?  
  <sub>喂，你看昨天那个综艺了吗？</sub>
- **나**：봤지! 마지막에 그 반전 실화야?  
  <sub>看了！最后那个反转是真的假的？</sub>
- **친구 민재**：완전 소름이었어. 근데 TMI인데, 나 그거 보다가 라면 두 개 먹었어.  
  <sub>超起鸡皮疙瘩。不过说个题外话，我看的时候吃了两包泡面。</sub>
- **나**：하하, 야식엔 라면, 국룰이지.  
  <sub>哈哈，夜宵配泡面，铁律嘛。</sub>
- **친구 민재**：인정. 근데 오늘 아침에 체중계 보고 멘붕 왔어.  
  <sub>确实。不过今早看了体重秤我崩溃了。</sub>
- **나**：아, 그건 좀 현타 오겠다.  
  <sub>啊，那确实会怀疑人生。</sub>
- **친구 민재**：그래서 오늘부터 다이어트 할 거야.  
  <sub>所以从今天开始减肥。</sub>
- **나**：에이, 그 말 벌써 열 번째거든?  
  <sub>哎，这话你都说第十次了好吗？</sub>

## 第 16 课　朋友间八卦与闲聊　<small>친구랑 수다</small>

会传话（-대）、会说自己看到的（-던데）、会追问、会保守秘密——这才是真正的"수다"。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 요즘 그 드라마 보고 있어? | 最近在看那部剧吗？ |  |
| 2 | 스포하지 마! | 别剧透！ |  |
| 3 | 결말 어떻게 될 것 같아? | 你觉得结局会怎样？ |  |
| 4 | 걔 요즘 누구랑 썸 타는 것 같던데? | 他/她最近好像在跟谁暧昧？ | 썸 타다 = 暧昧中；-던데：我观察到的 |
| 5 | 둘이 사귄대. | 听说他俩在一起了 | -대 = -다고 해，传话 |
| 6 | 헐, 언제부터? | 天哪，从什么时候开始？ |  |
| 7 | 나만 몰랐어? | 就我不知道？ |  |
| 8 | 솔직히 말해 봐. | 老实说吧 |  |
| 9 | 이건 비밀이야. 아무한테도 말하지 마. | 这是秘密，别告诉任何人 |  |
| 10 | 그건 좀 오바다. | 那有点太夸张了 | 오바 = over，夸张、过分 |

### ② 情景对话：你跟朋友素熙分享一个八卦

你扮演：**나**（两个角色都要练）

- **나**：야, 너 그 얘기 들었어? 준호랑 지민이 사귄대.  
  <sub>喂，你听说了吗？俊浩和智敏在一起了。</sub>
- **친구 소희**：헐, 진짜? 언제부터?  
  <sub>天哪，真的？什么时候开始的？</sub>
- **나**：한 달 됐대. 둘이 요즘 썸 타는 것 같긴 했는데.  
  <sub>听说一个月了。我就觉得他俩最近在暧昧。</sub>
- **친구 소희**：나만 몰랐어? 어쩐지 요즘 둘이 맨날 같이 다니더라.  
  <sub>就我不知道？难怪最近他俩天天一起。</sub>
- **나**：그치? 근데 이건 비밀이야. 아무한테도 말하지 마.  
  <sub>对吧？不过这是秘密，别告诉任何人。</sub>
- **친구 소희**：알았어. 근데 솔직히 말해 봐. 너도 좋아하는 사람 있지?  
  <sub>知道了。不过老实说，你也有喜欢的人吧？</sub>
- **나**：에이, 없어. 그건 좀 오바다.  
  <sub>哎，没有。你这也太夸张了。</sub>
- **친구 소희**：얼굴 빨개졌는데? 하하.  
  <sub>你脸都红了？哈哈。</sub>

### ③ 句型快反：-대（听说）/ -던데（我看到的）

> 动词 -ㄴ대/는대，形容词 -대，名词 -(이)래；-던데 是"我之前看到/感觉到的"。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| 听说明天下雨 | 내일 비 온대. |
| 听说那家店关门了 | 그 가게 문 닫았대. |
| 听说他要去留学 | 걔 유학 간대. |
| 那家店我去过，挺好吃的呀 | 거기 가 봤는데 맛있던데? |
| 她昨天看起来心情不好 | 걔 어제 기분 안 좋아 보이던데. |
| 听说期末考试出得很简单 | 기말고사 쉽게 나온대. |

### ④ 独白任务（录音 90 秒）

用半语给朋友讲一个"八卦"（可以编）：听说了什么（-대）、你观察到的迹象（-던데）、你的看法，最后让对方保密。

可用表达：`너 그 얘기 들었어?`　`~ㄴ대`　`어쩐지 요즘 ~던데`　`이건 비밀이야`
