## 第 69 课　价值观与人生观　<small>가치관과 인생관</small>

"你人生中最重要的是什么？"——能回答这种问题，说明你的韩语已经能表达"你是谁"。

| 2 | 저는 돈보다 시간을 더 중요하게 생각해요. | 我把时间看得比钱更重要 |  |
| 3 | 남들 눈치 보지 않고 사는 게 목표예요. | 目标是不看别人脸色地活着 |  |
| 4 | 후회 없이 살고 싶어요. | 想活得不后悔 |  |
| 5 | 예전에는 성공이 전부라고 생각했어요. | 以前我以为成功就是一切 |  |
| 6 | 나이가 들면서 생각이 많이 바뀌었어요. | 随着年龄增长，想法变了很多 |  |
| 7 | 결과보다 과정이 더 중요하다고 봐요. | 我认为过程比结果更重要 |  |

### ② 情景对话：深夜和朋友聊人生

你扮演：**나**（两个角色都要练）

- **친구 하준**：너는 인생에서 제일 중요한 게 뭐라고 생각해?  
  <sub>你觉得人生中最重要的是什么？</sub>
- **나**：음… 예전에는 무조건 성공이라고 생각했는데, 요즘은 좀 달라졌어.  
  <sub>嗯……以前觉得绝对是成功，最近有点变了。</sub>
- **친구 하준**：왜? 무슨 계기가 있었어?  
  <sub>为什么？有什么契机吗？</sub>
- **나**：작년에 아빠가 갑자기 입원하셨을 때, 일보다 가족이랑 보내는 시간이 훨씬 소중하다는 걸 느꼈어.  
  <sub>去年爸爸突然住院的时候，我感到和家人在一起的时间比工作珍贵得多。</sub>
- **친구 하준**：그렇구나. 나는 아직 돈이 제일 중요한 것 같아. 현실적으로.  
  <sub>这样啊。我还是觉得钱最重要。现实一点说。</sub>
- **나**：그 말도 맞아. 돈이 있어야 하고 싶은 걸 할 수 있으니까. 사람마다 가치관이 다른 거지.  
  <sub>你说的也对。有钱才能做想做的事。每个人价值观不同嘛。</sub>
- **친구 하준**：그럼 너 좌우명 같은 거 있어?  
  <sub>那你有座右铭之类的吗？</sub>
- **나**："일단 해 보자." 고민만 하다가 후회한 적이 많아서.  
  <sub>"先做做看。"因为我常常光纠结、最后后悔。</sub>

## 第 70 课　幸福与成功　<small>행복과 성공</small>

韩国社会竞争激烈，"행복"和"성공"是韩国人很常聊、也很有感触的话题。

| 3 | 퇴근하고 마시는 맥주 한 캔이 제 소확행이에요. | 下班后喝一罐啤酒就是我的小确幸 |  |

| 9 | 행복은 목적지가 아니라 과정인 것 같아요. | 幸福好像不是终点而是过程 |  |
| 10 | 지금 이 순간을 즐기려고 노력해요. | 我努力享受当下 |  |

### ② 情景对话：和同事聊"成功"

你扮演：**나**（两个角色都要练）

- **동료 은서**：리웨이 씨는 성공한 삶이 뭐라고 생각해요?  
  <sub>李伟你觉得成功的人生是什么？</sub>
- **나**：음, 남들이 보기에 성공한 것보다 제가 만족하는 삶이요.  
  <sub>嗯，比起别人眼里的成功，是我自己满意的人生。</sub>
- **동료 은서**：근데 한국에서는 그게 쉽지 않잖아요. 다들 연봉, 집, 차로 비교하니까요.  
  <sub>可在韩国这不容易嘛。大家都比年薪、房子、车。</sub>
- **나**：맞아요. 중국도 비슷해요. 근데 비교하기 시작하면 끝이 없더라고요.  
  <sub>对。中国也差不多。不过我发现一开始比较就没完没了。</sub>
- **동료 은서**：그럼 리웨이 씨는 어떻게 해요?  
  <sub>那你怎么办？</sub>
- **나**：어제의 저랑만 비교하려고 해요. 어제보다 한국어 한 문장이라도 더 말하면 그날은 성공이에요.  
  <sub>我尽量只和昨天的自己比。比昨天多说一句韩语，那天就算成功。</sub>
- **동료 은서**：와, 그거 좋다. 저도 해 봐야겠어요.  
  <sub>哇，这个好。我也得试试。</sub>
- **나**：그리고 소확행을 많이 만들어요. 퇴근길에 좋아하는 노래 듣는 것 같은 거요.  
  <sub>还有多创造小确幸。比如下班路上听喜欢的歌。</sub>

### ③ 句型快反：抽象观点：-는 것 같아요 / -다기보다는 / -아/어야 -(으)ㄹ 수 있다

> 谈抽象话题时用"제 생각에는"开头、用"-는 것 같아요"收尾，语气会更柔和，不像在说教。

| 与其说是钱的问题，不如说是心态问题 | 돈 문제라기보다는 마음가짐 문제인 것 같아요. |
| 得先爱自己，才能爱别人 | 자신을 먼저 사랑해야 남도 사랑할 수 있어요. |
| 我的小确幸是周末睡懒觉 | 제 소확행은 주말에 늦잠 자는 거예요. |

| 你什么时候觉得最幸福？ | 언제 제일 행복하다고 느껴요? |

### ④ 独白任务（录音 3 分钟）

谈谈"幸福"和"成功"：你最近一次觉得幸福是什么时候？你的小确幸是什么？你怎么定义成功？你怎么看"和别人比较"？最后给五年前的自己一句建议。

可用表达：`최근에 제일 행복했던 건 ~`　`제 소확행은 ~`　`제가 생각하는 성공은 ~`　`비교하기 시작하면 ~`　`5년 전의 나한테 ~라고 말해 주고 싶어요`

### ② 情景对话：和朋友讨论"学外语还有必要吗"

你扮演：**나**（两个角色都要练）

- **친구 도윤**：요즘 번역기 너무 좋아져서 외국어 공부할 필요가 있나 싶어.  
  <sub>最近翻译软件太好用了，我在想学外语还有没有必要。</sub>
- **나**：그 말도 일리는 있어. 간단한 건 번역기로 다 되니까.  
  <sub>这话也有道理。简单的东西翻译软件都能搞定。</sub>
- **친구 도윤**：그렇지? 10년 후에는 이어폰만 끼면 다 통역될 거야.  
  <sub>对吧？十年后戴个耳机就全能翻译了。</sub>
- **나**：그럴 수도 있지. 근데 나는 그래도 직접 말하는 건 대체할 수 없다고 봐.  
  <sub>有可能。不过我还是认为自己开口说是无法替代的。</sub>
- **친구 도윤**：왜?  
  <sub>为什么？</sub>
- **나**：번역기는 말은 전해도 마음은 못 전하잖아. 농담이나 분위기 같은 거. 그리고 언어를 배우면 그 나라 사람들의 생각 방식도 이해하게 되고.  
  <sub>翻译软件能传话但传不了心意嘛。比如玩笑、氛围。而且学了语言，也会理解那个国家的人的思维方式。</sub>
- **친구 도윤**：듣고 보니 그렇네. 네가 한국어로 농담하는 거 보면 확실히 다르긴 해.  
  <sub>听你一说也是。看你用韩语开玩笑确实不一样。</sub>
- **나**：하하, 그치? 기술은 결국 어떻게 쓰느냐에 달린 것 같아.  
  <sub>哈哈，对吧？我觉得技术最终取决于怎么用。</sub>

### ③ 句型快反：讨论科技：-(으)ㄹ 수도 있다 / -(으)ㄴ/는 만큼 / -에 따라 다르다 / -(으)ㄹ지도 모르다

| 你觉得AI对生活有帮助吗？ | AI가 생활에 도움이 된다고 생각해요? |

### ④ 独白任务（录音 3 分钟）

### ③ 句型快反：-(으)려고 -고 있어요 / -다 보니까 / -(으)ㄴ다고 -냐고 하는 사람도 있어요

> "-(으)ㄴ다고 뭐가 달라지냐"是韩国人质疑时很常用的句式（……又能怎样呢）。

| 提示（5秒内开口） | 参考答案 |

| 为了保护环境，我在少用塑料袋 | 환경을 위해서 비닐봉지를 덜 쓰려고 하고 있어요. |
