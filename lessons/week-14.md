## 第 66 课　推测与可能性　<small>추측 표현</small>

韩国人说话很少百分之百肯定。区分各种推测：-겠다（当场判断）、-(으)ㄹ 것 같다、-나 보다、-(으)ㄹ지도 모르다、-(으)ㄹ 텐데。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 와, 맛있겠다! | 哇，看起来好好吃！ | -겠다：看到/听到后当场的判断 |
| 2 | 내일 비 올 것 같아요. | 明天好像要下雨 |  |
| 3 | 민수 씨 오늘 바쁜가 봐요. | 敏秀今天好像很忙（看他一直没回消息） | -나 보다/-(으)ㄴ가 보다：根据线索推测 |
| 4 | 혹시 길이 막힐지도 몰라요. | 说不定会堵车 |  |
| 5 | 지금쯤 도착했을 거예요. | 现在应该已经到了 | -았/었을 거예요：对过去的推测 |
| 6 | 많이 피곤할 텐데 좀 쉬어요. | 你肯定很累了，休息一下吧 | -(으)ㄹ 텐데：推测 + 关心/建议 |

## 第 67 课　后悔与假设　<small>후회와 가정</small>

"早知道就……""要是当时……就好了""如果我是你……"——这些是讲经历和谈心时最常用的表达。

| 2 | 그 말은 하지 말걸 그랬어. | 那句话我不该说的 |  |
| 3 | 좀 더 일찍 출발했으면 좋았을 텐데요. | 要是早点出发就好了 |  |
| 4 | 그때 한국에 안 왔더라면 지금의 저는 없었을 거예요. | 要是当时没来韩国，就没有现在的我 | -았/었더라면：与过去事实相反的假设 |
| 5 | 미리 알았으면 도와줬을 텐데. | 要是早知道我就帮你了 |  |

| 9 | 후회해도 소용없어요. | 后悔也没用了 |  |
| 10 | 지난 일은 잊어버리자. | 过去的事就忘了吧 |  |

### ② 情景对话：和朋友聊错过的机会

你扮演：**나**（两个角色都要练）

- **친구 은우**：나 그 회사 지원 안 한 거 너무 후회돼. 친구가 거기 붙었대.  
  <sub>我好后悔没投那家公司。听说我朋友考上了。</sub>
- **나**：아, 진짜? 그때 왜 안 했어?  
  <sub>啊，真的？当时为什么没投？</sub>
- **친구 은우**：경쟁률이 너무 높아서 어차피 안 될 줄 알았어. 그냥 지원해 볼걸 그랬어.  
  <sub>竞争率太高，以为反正不行。早知道就投投看了。</sub>
- **나**：그 마음 알아. 나도 작년에 장학금 신청 안 했다가 엄청 후회했잖아.  
  <sub>我懂。我去年也没申请奖学金，后悔死了。</sub>
- **친구 은우**：그래서 그다음에 어떻게 했어?  
  <sub>那后来怎么办的？</sub>
- **나**：이번 학기에 바로 신청했지. 후회해도 소용없으니까 다음 기회를 잡는 게 중요하더라고.  
  <sub>这学期马上就申请了。后悔也没用，抓住下次机会才重要。</sub>
- **친구 은우**：맞다. 그 회사 하반기에도 채용한대.  
  <sub>对。听说那家公司下半年也招人。</sub>
- **나**：그럼 이번엔 꼭 지원해. 내가 너라면 지금부터 준비할 거야.  
  <sub>那这次一定要投。如果我是你，从现在就开始准备。</sub>

### ③ 句型快反：-(으)ㄹ걸 그랬다 / -았/었더라면 / -(으)면 -(으)ㄹ 텐데

> -(으)ㄹ걸 그랬어요 = 早知道就（做）了；-지 말걸 그랬어요 = 早知道就不（做）了；-았/었더라면 ~았/었을 거예요 = 要是当时……就会……

| 提示（5秒内开口） | 参考答案 |
|---|---|
| 早知道就多睡一会儿了 | 좀 더 잘걸 그랬어요. |
| 早知道就不吃那么多了 | 그렇게 많이 먹지 말걸 그랬어요. |
| 要是当时好好学习，现在就轻松了 | 그때 열심히 공부했더라면 지금 편했을 거예요. |
| 要是有时间的话就一起去了 | 시간이 있었으면 같이 갔을 텐데요. |
| 如果我是你，我会先道歉 | 제가 너라면 먼저 사과할 것 같아. |
| 如果明天放假你想做什么？ | 내일 쉬면 뭐 하고 싶어요? |

### ④ 独白任务（录音 2 分钟）

讲一件你后悔的事：发生了什么 → "早知道就……"（-(으)ㄹ걸 그랬다）→ "要是当时……就会……"（-았/었더라면）→ 你从中学到了什么。再回答：如果能回到过去一天，你会选哪一天？

可用表达：`그때 ~ 때문에 ~ 안 했는데요`　`~ㄹ걸 그랬어요`　`그때 ~았더라면 ~았을 거예요`　`그래서 지금은 ~`

## 第 68 课　条件与让步　<small>조건과 양보</small>

"只要……就……""即使……也……""无论……都……"——说服人、讲道理、表决心时离不开这些句型。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 연습만 하면 누구나 할 수 있어요. | 只要练习，谁都能做到 | -기만 하면 |
| 2 | 비가 와도 갈 거예요. | 即使下雨也要去 |  |
| 3 | 아무리 바빠도 밥은 챙겨 먹어요. | 再忙也要好好吃饭 | 아무리 -아/어도 |
| 4 | 힘들더라도 끝까지 해 봐요. | 即使很辛苦也坚持到底吧 | -더라도：更强的让步 |
| 5 | 시간이 있을 때마다 단어를 외워요. | 每次有时间就背单词 |  |

### ② 情景对话：朋友想放弃韩语考试

你扮演：**나**（两个角色都要练）

- **중국 친구 샤오린**：나 TOPIK 6급 그냥 포기할까 봐. 아무리 공부해도 점수가 안 올라.  
  <sub>我想干脆放弃TOPIK 6级了。怎么学分数都不涨。</sub>
- **나**：힘든 거 알아. 그렇다고 포기할 수는 없잖아. 여기까지 왔는데.  
  <sub>我知道很难。但也不能因此放弃嘛。都走到这一步了。</sub>
- **중국 친구 샤오린**：쓰기가 진짜 안 늘어.  
  <sub>写作真的没进步。</sub>
- **나**：쓰기는 매일 조금씩 쓰기만 하면 확실히 늘어. 나도 그랬어.  
  <sub>写作只要每天写一点，肯定会进步。我也是这样。</sub>
- **중국 친구 샤오린**：근데 일도 해야 돼서 시간이 없어.  
  <sub>可还要上班，没时间。</sub>
- **나**：아무리 바빠도 하루 20분은 낼 수 있잖아. 출퇴근할 때 해도 되고.  
  <sub>再忙一天20分钟总能挤出来吧。上下班路上做也行。</sub>
- **중국 친구 샤오린**：음… 그럼 시험까지만 버텨 볼까?  
  <sub>嗯……那就坚持到考试？</sub>
- **나**：응. 결과가 안 좋더라도 해 본 거랑 안 해 본 거는 다르니까. 내가 할 수 있는 한 도와줄게.  
  <sub>嗯。即使结果不好，试过和没试过也不一样。只要我能做到我就帮你。</sub>

### ③ 句型快反：-기만 하면 / -아/어도 / 아무리 -아/어도 / -더라도 / -는 한

> -아/어도 是一般的"即使"；-더라도 假设性更强、语气更坚决；아무리 + -아/어도 = "再怎么……也……"。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| 只要按时吃药就会好 | 약만 제때 먹기만 하면 나을 거예요. |
| 即使贵也想买 | 비싸도 사고 싶어요. |
| 再怎么累也要洗了脸再睡 | 아무리 피곤해도 세수는 하고 자요. |
| 即使失败也不后悔 | 실패하더라도 후회는 안 할 거예요. |
| 只要我在韩国，就会继续学韩语 | 한국에 있는 한 계속 한국어 공부할 거예요. |
| 不是越多越好 | 많으면 많을수록 좋은 건 아니에요. |

## 第 69 课　转述进阶：问句、命令、提议的转述　<small>간접 화법</small>

"他问我……""老师让我……""朋友提议……"——口语里转述别人的话非常多，而且常用缩略形式（-냬요、-래요、-재요）。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| 1 | 선생님이 내일까지 숙제 내래요. | 老师说让明天之前交作业 | 命令：-(으)라고 하다 → -(으)래요 |

| 3 | 엄마가 밥 먹었냐고 물어보셨어요. | 妈妈问我吃饭没 | 问句：-냐고 하다 → -냬요 |
| 4 | 사장님이 오늘 일찍 가도 된대요. | 老板说今天可以早点走 |  |

| 8 | 언제 오냐고 계속 물어봐요. | 一直在问什么时候来 |  |

| 10 | 제가 뭐라고 했냐면요… | 我说了什么呢…… |  |

### ② 情景对话：你把教授的话转述给没去组会的同学

你扮演：**나**（两个角色都要练）

- **동기 서준**：오늘 랩 미팅 못 갔는데, 교수님이 뭐라고 하셨어?  
  <sub>今天没去组会，教授说了什么？</sub>
- **나**：다음 주 금요일까지 중간 보고서 내래.  
  <sub>说下周五之前交中期报告。</sub>
- **동기 서준**：헐, 벌써? 분량은 얼마나 된대?  
  <sub>天哪，这么快？说要多少字？</sub>
- **나**：10쪽 이내로 쓰래. 그리고 너한테 실험 결과 좀 정리해 달래.  
  <sub>说10页以内。还让你整理一下实验结果。</sub>
