## 第 51 课　委婉说法与读懂潜台词　<small>돌려 말하기</small>

韩国人很少直接说"不"。"생각해 볼게요"往往等于"不行"。学会委婉地说，也学会听懂别人委婉的话。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 한번 생각해 볼게요. | 我考虑一下（常常是委婉的拒绝） |  |
| 2 | 그건 좀 어려울 것 같은데요. | 那个恐怕有点难（=不行） |  |
| 3 | 마음은 감사한데요… | 心意我很感谢，但是…… |  |
| 4 | 제가 요즘 좀 여유가 없어서요. | 我最近不太有余力（时间/钱/精力） |  |
| 5 | 나쁘지 않은데요? | 还不错啊？（其实是夸奖） | 韩国人常用双重否定表示肯定 |
| 6 | 좀 독특하네요. | 挺独特的（可能是委婉的"奇怪"） |  |
| 7 | 다음에 기회 되면 꼭 같이 해요. | 下次有机会一定一起（=这次不去） |  |
| 8 | 혹시 괜찮으시면… | 如果您方便的话……（委婉请求） |  |
| 9 | 제가 잘못 이해한 걸 수도 있는데요. | 可能是我理解错了……（委婉指出对方错误） |  |
| 10 | 그런 방법도 있겠네요. | 也可以那样呢（不太同意时的缓冲） |  |

### ② 情景对话：前辈拉你周末去登山社团，你不太想去

你扮演：**나**（两个角色都要练）

- **선배 지훈**：리웨이 씨, 이번 주 토요일에 등산 동호회 같이 갈래요? 새벽 5시 출발이에요.  
  <sub>李伟，这周六一起去登山社团吗？凌晨5点出发。</sub>
- **나**：와, 새벽 5시요? 마음은 진짜 감사한데요…  
  <sub>哇，凌晨5点？心意真的很感谢，但是……</sub>
- **선배 지훈**：왜요? 등산 별로 안 좋아해요?  
  <sub>怎么了？不太喜欢登山吗？</sub>
- **나**：아니요, 그런 건 아닌데, 제가 요즘 논문 때문에 좀 여유가 없어서요.  
  <sub>不是不是，只是我最近因为论文实在没什么余力。</sub>
- **선배 지훈**：아, 그렇구나. 그럼 다음 달은 어때요?  
  <sub>啊，这样啊。那下个月怎么样？</sub>
- **나**：음, 한번 생각해 볼게요. 다음에 기회 되면 꼭 같이 가요.  
  <sub>嗯，我考虑一下。下次有机会一定一起去。</sub>
- **선배 지훈**：하하, 알겠어요. 부담 갖지 마요.  
  <sub>哈哈，知道了。别有压力。</sub>
- **나**：신경 써 주셔서 감사해요, 선배.  
  <sub>谢谢前辈费心。</sub>

### ③ 句型快反：直接说法 → 委婉说法

> 提示是"直接但失礼"的说法，你要换成韩国人会用的委婉版本。

| 你说错了（委婉）：会议不是三点吗？ | 제가 잘못 이해한 걸 수도 있는데요, 혹시 회의 세 시 아니에요? |
| 这个太难吃了（委婉） | 음, 맛이 좀 독특하네요. |
| 我没钱（委婉） | 요즘 좀 사정이 있어서요. |
| 帮我做一下（委婉请求） | 혹시 시간 괜찮으시면 이것 좀 봐 주실 수 있을까요? |

### ④ 独白任务（录音 90 秒）

三段委婉表达：① 朋友约你去一个你不想去的聚会，委婉拒绝 ② 同事的方案有问题，委婉指出 ③ 朋友做的菜不好吃，委婉评价。每段都不能直接说"不"。

可用表达：`마음은 감사한데요`　`제가 요즘 좀 ~해서요`　`그런 방법도 있겠지만`　`맛이 좀 독특하네요`

## 第 52 课　幽默、玩笑与吐槽　<small>농담과 드립</small>

会接玩笑的外国人最受欢迎。学会韩国人常用的吐槽、自嘲和接梗方式。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 농담이에요, 농담. | 开玩笑的，开玩笑的 |  |
| 2 | 아, 진짜 웃겨 죽겠다. | 啊，笑死我了 |  |
| 3 | 드립 미쳤다. | 这梗绝了 | 드립：玩笑、段子 |
| 4 | 너 진짜 웃기다. | 你真搞笑 |  |
| 5 | 나 원래 이런 사람이야. | 我本来就是这样的人（自嘲） |  |
| 6 | 그건 인정할게. | 这个我承认 |  |
| 7 | 또 시작이다. | 又来了（吐槽对方老毛病） |  |

| 9 | 장난치지 마. | 别闹了 |  |

### ② 情景对话：朋友又说要减肥

你扮演：**나**（两个角色都要练）

- **친구 준서**：나 오늘부터 진짜 다이어트 한다. 이번엔 진심이야.  
  <sub>我从今天开始真的减肥了。这次是认真的。</sub>
- **나**：또 시작이다. 그 말 이번 달에만 세 번째야.  
  <sub>又来了。这话光这个月就第三次了。</sub>
- **친구 준서**：야, 이번엔 다르다니까. 저녁도 샐러드 먹을 거야.  
  <sub>喂，这次不一样。晚饭也要吃沙拉。</sub>
- **나**：샐러드에 치킨 토핑 추가하는 거 아니고?  
  <sub>不会是沙拉上加炸鸡吧？</sub>
- **친구 준서**：하하, 그건 인정. 근데 닭가슴살이야, 닭가슴살.  
  <sub>哈哈，这个我承认。不过是鸡胸肉，鸡胸肉。</sub>
- **나**：농담이야, 농담. 나도 같이 할게. 나도 요즘 배가 장난 아니거든.  
  <sub>开玩笑啦。我也一起。我最近肚子也很夸张。</sub>
- **친구 준서**：오, 진짜? 그럼 오늘 저녁은 마지막 만찬으로 삼겹살?  
  <sub>哦，真的？那今晚当作最后的晚餐吃五花肉？</sub>
- **나**：말이 되는 소리를 해. 하하, 근데 좋아.  
  <sub>你说点靠谱的话吧。哈哈，不过好啊。</sub>

### ③ 句型快反：接玩笑 / 自嘲 / 吐槽

> 韩国人的玩笑很多是"轻吐槽"，关键是语气轻松，说完加个"하하"或"농담이야"。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| （朋友讲冷笑话）啊，好冷……别讲了 | 아, 추워… 그만해. |
| （被朋友吐槽）这个我承认 | 그건 인정. |
| （自嘲）我天生就是路痴 | 나 원래 길치야. 태어날 때부터. |
| （朋友第五次说要减肥）说点靠谱的吧 | 말이 되는 소리를 해. 벌써 다섯 번째야. |
| 刚才那个梗太绝了 | 방금 드립 미쳤다. |
| 开玩笑的，别生气 | 농담이야, 화내지 마. |

### ④ 独白任务（录音 90 秒）

模拟和好朋友的轻松对话（半语），至少包含：一次吐槽对方、一次自嘲、一次接住对方的玩笑、一次"농담이야"。可以一人分饰两角。

可用表达：`또 시작이다`　`나 원래 이런 사람이야`　`그건 인정`　`농담이야, 농담`

## 第 53 课　说服、谈判与讨价还价　<small>설득과 협상</small>

能说服室友、和房东谈条件、和同事协调分工——讲理由、预判反对、给出折中方案。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 제 얘기 한번 들어 보세요. | 您先听我说说 |  |
| 2 | 이렇게 하면 서로 좋잖아요. | 这样对双方都好嘛 |  |
| 3 | 장기적으로 보면 이게 더 이득이에요. | 从长远看这个更划算 |  |
| 4 | 그 대신 설거지는 제가 할게요. | 作为交换，碗我来洗 | 句型：그 대신 (제가) ~ 할게요 |
| 5 | 반반씩 양보하면 어떨까요? | 我们各退一步怎么样？ |  |
| 6 | 혹시 조금만 조정해 주실 수 있을까요? | 能稍微调整一下吗？ |  |
| 7 | 그건 제가 받아들이기 좀 어려워요. | 那个我有点难以接受 |  |
| 8 | 그럼 이렇게 해 보는 건 어때요? | 那这样试试怎么样？ |  |
| 9 | 일단 한 달만 해 보고 다시 얘기해요. | 先试一个月再谈 |  |
| 10 | 좋아요, 그걸로 하죠. | 好，就这么定了 |  |

### ② 情景对话：和房东谈续租的月租

你扮演：**나**（两个角色都要练）

- **나**：사장님, 계약 연장 때문에 연락드렸는데요.  
  <sub>老板，我是为了续租的事联系您。</sub>
- **집주인**：아, 네. 이번에는 월세를 5만 원 올려야 할 것 같아요.  
  <sub>啊，好的。这次月租可能得涨5万。</sub>
- **나**：음, 그건 제가 받아들이기 좀 어려워요. 요즘 사정이 좀 빠듯해서요.  
  <sub>嗯，那个我有点难以接受。最近手头有点紧。</sub>
- **집주인**：근데 요즘 주변 시세가 다 올라서요.  
  <sub>可最近周边行情都涨了。</sub>
- **나**：이해해요. 그럼 반반씩 양보해서 2만 5천 원만 올리면 어떨까요?  
  <sub>我理解。那我们各退一步，只涨2万5怎么样？</sub>
- **집주인**：음… 그건 좀 적은데.  
  <sub>嗯……那有点少。</sub>
- **나**：그 대신 2년 계약으로 할게요. 장기적으로 보면 사장님한테도 이득이잖아요.  
  <sub>作为交换我签两年。从长远看对您也划算嘛。</sub>
- **집주인**：듣고 보니 그렇네요. 좋아요, 그걸로 하죠.  
  <sub>听你这么一说也是。好，就这么定了。</sub>

### ③ 句型快反：说服三步：理由（-잖아요）→ 让步（그 대신）→ 折中（-(으)면 어떨까요?）

> 韩国式说服的关键是"先认同对方，再给好处"。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| 这样对我们都好嘛 | 이렇게 하면 우리 둘 다 좋잖아요. |
| 作为交换我来打扫 | 그 대신 청소는 제가 할게요. |
| 先试一周怎么样？ | 일단 일주일만 해 보면 어떨까요? |
| 价格能稍微调整一下吗？ | 가격을 조금만 조정해 주실 수 있을까요? |
| 从长远看更省钱 | 장기적으로 보면 돈이 더 절약돼요. |
| 好，那就这么定了 | 좋아요, 그럼 그렇게 해요. |

### ④ 独白任务（录音 2 分钟）

说服室友（或家人）一起养一只猫：讲 2 个理由、预判对方 2 个反对意见并回应、提出一个折中方案（谁负责什么）、最后达成协议。

可用表达：`내 얘기 한번 들어 봐`　`고양이 키우면 ~잖아`　`물론 ~ 걱정되겠지만`　`그 대신 ~는 내가 할게`　`일단 한 달만 해 보자`

## 第 54 课　惯用语与俗语活用　<small>관용어·속담</small>

韩国人聊天时惯用语用得非常多。用对一个，对方会立刻觉得"这人韩语真好"。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 그 사람 발이 진짜 넓어요. | 那个人人脉特别广 | 발이 넓다：交际广 |
| 2 | 제 친구는 눈이 너무 높아요. | 我朋友眼光太高了 | 눈이 높다：挑剔、要求高 |
| 3 | 우리 엄마는 손이 커요. | 我妈做饭/给东西特别大方（量大） | 손이 크다 |
| 4 | 요즘 일이 너무 많아서 눈코 뜰 새 없어요. | 最近事太多，忙得不可开交 |  |
| 5 | 그 얘기 듣고 귀가 솔깃했어요. | 听到那个话我动心了 |  |
| 6 | 입이 무거운 사람이니까 믿어도 돼요. | 他嘴很严，可以信任 | 입이 무겁다 ↔ 입이 가볍다 |
| 7 | 시험 결과 나올 때까지 손에 땀을 쥐었어요. | 等考试结果时紧张得手心冒汗 |  |
| 8 | 티끌 모아 태산이에요. | 积少成多（积土成山） | 俗语 |
| 9 | 가는 말이 고와야 오는 말이 곱죠. | 你对别人客气，别人才会对你客气 | 俗语 |
| 10 | 그건 누워서 떡 먹기예요. | 那简直易如反掌（躺着吃年糕） | 俗语 |

### ② 情景对话：和朋友聊共同的熟人

你扮演：**나**（两个角色都要练）

- **친구 서아**：너 민호 선배 알지? 이번에 또 회사 옮긴대.  
  <sub>你认识敏浩前辈吧？听说这次又换公司了。</sub>
- **나**：아, 그 선배 진짜 발이 넓잖아. 아는 사람이 엄청 많아.  
  <sub>啊，那个前辈人脉真的广嘛。认识超多人。</sub>
- **친구 서아**：맞아. 근데 연애는 왜 안 하는지 모르겠어.  
  <sub>对。不过不知道他为什么不谈恋爱。</sub>
- **나**：눈이 너무 높아서 그렇대. 본인 입으로 말했어.  
  <sub>听说是眼光太高了。他自己说的。</sub>
- **친구 서아**：하하. 근데 이 얘기 다른 사람한테 하지 마.  
  <sub>哈哈。不过这话别跟别人说。</sub>
- **나**：걱정 마, 나 입 무거운 거 알잖아.  
  <sub>放心，你知道我嘴很严的。</sub>
- **친구 서아**：알지. 아, 그리고 나 요즘 회사 일 때문에 눈코 뜰 새 없어.  
  <sub>知道。啊，还有我最近因为公司的事忙得不可开交。</sub>
- **나**：힘내. 이번 프로젝트 끝나면 내가 맛있는 거 쏠게.  
  <sub>加油。这个项目结束我请你吃好吃的。</sub>

### ③ 句型快反：看意思 → 说惯用语

> 惯用语要整句记，替换主语就能用。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| 他人脉很广 | 그 사람 발이 넓어요. |
| 她眼光很高 | 그 친구는 눈이 높아요. |
| 最近忙得不可开交 | 요즘 눈코 뜰 새 없어요. |

## 第 55 课　模糊表达与给自己留余地　<small>애매하게 말하기</small>

韩国人很少把话说死。"그런 편이에요""그럴 수도 있죠""글쎄요"——学会模糊表达，你的话会显得更成熟、更不容易得罪人。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 글쎄요, 잘 모르겠네요. | 这个嘛，我也不太清楚 |  |
| 2 | 좋다면 좋고, 아니라면 아닌 것 같아요. | 说好也好，说不好也不好 |  |
| 3 | 그런 편이에요. | 算是那样吧 |  |
| 4 | 꼭 그렇다고는 할 수 없죠. | 也不能说一定是那样 |  |
| 5 | 상황에 따라 다를 것 같아요. | 可能要看情况 |  |
| 6 | 반은 맞고 반은 틀린 것 같아요. | 好像一半对一半不对 |  |
| 7 | 아직 확실하진 않은데요. | 还不太确定 |  |
| 8 | 일단 해 보고 생각해 볼게요. | 先做做看再考虑 |  |
| 9 | 나쁘진 않은데, 아주 좋다고 하기도 좀… | 不坏，但要说很好也有点…… |  |
| 10 | 뭐, 그럴 수도 있죠. | 嗯，也有可能吧 |  |

### ② 情景对话：朋友问你对她新男朋友的印象

你扮演：**나**（两个角色都要练）

- **친구 수아**：어제 내 남자친구 처음 봤잖아. 어땠어? 솔직하게!  
  <sub>昨天你第一次见我男朋友嘛。怎么样？老实说！</sub>
- **나**：음… 글쎄, 한 번 봐서 잘 모르겠는데, 착해 보이긴 하더라.  
  <sub>嗯……这个嘛，只见了一面不太清楚，不过看起来挺善良的。</sub>
- **친구 수아**：근데 좀 말이 없지 않았어?  
  <sub>不过是不是有点话少？</sub>
- **나**：조용한 편이긴 했지. 근데 처음 만나는 자리라 긴장해서 그럴 수도 있고.  
  <sub>算是比较安静吧。不过第一次见面可能是紧张了。</sub>
- **친구 수아**：맞아, 원래는 말 엄청 많아. 하하.  
  <sub>对，他本来话特别多。哈哈。</sub>
- **나**：그럼 다음에 만나면 더 잘 알 수 있겠다. 너한테 잘해 주는 게 제일 중요하지.  
  <sub>那下次见面就能更了解了。最重要的是对你好。</sub>
- **친구 수아**：그건 진짜 잘해 줘.  
  <sub>那他真的对我很好。</sub>
- **나**：그럼 됐지! 네가 행복해 보여서 좋다.  
  <sub>那就够了！看你很幸福我也开心。</sub>

### ③ 句型快反：把话说"软"：-(으)ㄴ/는 편이다 / -(으)ㄹ 수도 있다 / -다고는 할 수 없다 / -긴 하다

> "-긴 하는데/하지만"（……是……，不过）是最好用的模糊句型：맛있긴 한데 좀 비싸요。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| 他算是比较内向的 | 그 사람은 내성적인 편이에요. |
| 好吃是好吃，就是有点贵 | 맛있긴 한데 좀 비싸요. |
| 也不能说他错了 | 그 사람이 틀렸다고는 할 수 없죠. |
| 也有可能是误会 | 오해일 수도 있어요. |
| 这个嘛，得看情况 | 글쎄요, 상황에 따라 다르죠. |
| 我还没决定好 | 아직 확실하게 정하진 않았어요. |

### ④ 独白任务（录音 90 秒）

三个"不好直说"的问题，用模糊表达回答：① 朋友问"我新剪的头发好看吗？"（其实一般）② 同事问"你觉得我们组长怎么样？" ③ 家人问"你明年会回国吗？"（还没决定）。

可用表达：`글쎄요`　`~긴 한데`　`~ 편이에요`　`~ㄹ 수도 있죠`　`아직 확실하진 않은데요`
