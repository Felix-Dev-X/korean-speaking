## 第 05 课　咖啡店与餐厅　<small>카페·식당 주문</small>

点单不只是"名词+주세요"——要能提要求（少甜、去洋葱、分开结账），还要听懂店员的追问。

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 아이스 아메리카노 한 잔이요. | 一杯冰美式 | 点单只要"名词+이요"就够了 |
| 2 | 포장해 주세요. / 먹고 갈게요. | 打包／在这儿吃 | 店员会问"드시고 가세요?" |
| 3 | 샷 추가해 주세요. | 加一份浓缩 |  |
| 4 | 덜 달게 해 주실 수 있어요? | 能做得少甜一点吗？ |  |
| 5 | 저기요, 주문할게요! | 你好，我要点单！ | 在餐厅叫服务员用"저기요"或"여기요" |
| 6 | 이거 많이 매워요? | 这个很辣吗？ |  |
| 7 | 양파는 빼 주세요. | 洋葱请去掉 |  |

### ③ 句型快反：-해 주세요 / -돼요? 快速点单

> 提要求用"-해 주세요/-빼 주세요"，问能不能用"-돼요?"——这两个句型能解决90%的点单问题。

| 能刷卡吗？ | 카드 돼요? |
| 不要冰块 | 얼음은 빼 주세요. |
| 这里能续杯吗？ | 여기 리필 돼요? |
| （店员问几位）我们四位 | 네 명이요. |
| 请给我一根吸管 | 빨대 하나 주세요. |

## 第 06 课　便利店与购物　<small>편의점·쇼핑</small>

会问颜色尺码、会试穿、会砍价、会退换货——购物时不再只会点头。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 봉투 하나 주세요. | 请给我一个袋子 | 店员会问"봉투 필요하세요?" |
| 2 | 이거 데워 주실 수 있어요? | 这个能帮我加热吗？ |  |
| 3 | 이거 1+1이에요? | 这个是买一送一吗？ | 1+1 读作[원 플러스 원] |
| 4 | 그냥 구경하는 거예요. | 我就随便看看 | 店员过来推销时用 |
| 5 | 이거 다른 색 있어요? | 这个有别的颜色吗？ |  |
| 6 | 입어 봐도 돼요? | 可以试穿吗？ |  |
| 7 | 한 사이즈 큰 거 있어요? | 有大一号的吗？ |  |
| 8 | 좀 깎아 주시면 안 돼요? | 能便宜一点吗？ | 传统市场可以试，商场一般不行 |

### ② 情景对话：在服装店

  <sub>好的，您随便看。这个是这季新品。</sub>
- **나**：오, 예쁘네요. 이거 다른 색도 있어요?  
  <sub>哦，挺好看的。这个有别的颜色吗？</sub>
- **점원**：네, 검은색이랑 베이지색 있어요.  
  <sub>有，有黑色和米色。</sub>
- **나**：베이지색으로 입어 봐도 돼요?  
  <sub>米色的能试一下吗？</sub>
- **점원**：그럼요. 피팅룸은 저쪽이에요.

### ③ 句型快反：购物高频句

> 每句都要能在店员面前"脱口而出"，不需要组织语言。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| 这个多少钱？ | 이거 얼마예요? |
| 有没有便宜点的？ | 좀 더 싼 거 있어요? |
| （店员问要不要袋子）不用了 | 봉투는 괜찮아요. |
| 这个是昨天买的，想换个尺码 | 이거 어제 샀는데 사이즈 교환하고 싶어요. |
| 能帮我包装成礼物吗？ | 선물 포장 해 주실 수 있어요? |
| 我再考虑一下 | 좀 더 생각해 볼게요. |

### ④ 独白任务（录音 60 秒）

你网购的鞋小了，去店里（或打电话）要求换货。要说明：什么时候买的、什么问题、想换成什么，并问运费/差价怎么算。

可用表达：`며칠 전에 여기서 샀는데요`　`신어 보니까 좀 작더라고요`　`한 사이즈 큰 걸로 교환하고 싶어요`　`배송비는 어떻게 돼요?`

## 第 07 课　交通与问路　<small>교통·길 묻기</small>

会问路、会坐车、会跟出租车司机沟通，还要听懂对方指路时的一长串话。

| 5 | 몇 번 출구로 나가야 돼요? | 要从几号出口出去？ |  |
| 6 | 기사님, 서울역으로 가 주세요. | 师傅，去首尔站 | 出租车、公交司机都叫"기사님" |

### ② 情景对话：在地铁站向一位阿姨问路

你扮演：**나**（两个角色都要练）

- **나**：저, 실례지만 경복궁 가려면 어떻게 가야 돼요?  
  <sub>那个，不好意思，去景福宫要怎么走？</sub>
- **아주머니**：경복궁이요? 3호선 타고 경복궁역에서 내리면 돼요.  
  <sub>景福宫？坐3号线在景福宫站下就行。</sub>
- **나**：여기서 바로 타면 돼요?  
  <sub>在这儿直接坐就行吗？</sub>
- **아주머니**：아니요, 여긴 2호선이라서 을지로3가에서 갈아타야 돼요.  
  <sub>不是，这里是2号线，要在乙支路3街换乘。</sub>
- **나**：아, 을지로3가요. 몇 번 출구로 나가야 돼요?  
  <sub>啊，乙支路3街。要从几号出口出去？</sub>
- **아주머니**：5번 출구로 나가면 바로 앞이에요.  
  <sub>从5号出口出去就在眼前。</sub>
- **나**：정말 감사합니다!  
  <sub>真是太感谢了！</sub>
- **아주머니**：아니에요, 조심해서 가요.  
  <sub>不客气，路上小心。</sub>

### ④ 独白任务（录音 60 秒）

## 第 08 课　医院、药店、银行　<small>병원·약국·은행</small>

生病时能准确描述症状，办事时能说清来意——这是在韩国生活的"保命技能"。

### ② 情景对话：在内科看病

你扮演：**나**（两个角色都要练）

- **의사**：어디가 불편해서 오셨어요?  
  <sub>您哪里不舒服？</sub>
- **나**：어제부터 목이 너무 아프고 열이 좀 있어요.  
  <sub>从昨天开始嗓子特别疼，还有点发烧。</sub>
- **의사**：기침도 하세요?  
  <sub>也咳嗽吗？</sub>
- **나**：네, 밤에 기침이 심해서 잠을 잘 못 잤어요.  
  <sub>是的，晚上咳得厉害，没睡好。</sub>
- **의사**：목 좀 볼게요. 아 해 보세요… 많이 부었네요. 감기 같아요.  
  <sub>我看看嗓子。张嘴"啊"……肿得挺厉害。像是感冒。</sub>
- **나**：혹시 주사 맞아야 돼요?  
  <sub>需要打针吗？</sub>
- **의사**：아니요, 약만 드셔도 괜찮을 거예요. 3일 치 처방해 드릴게요.  
  <sub>不用，吃药就行。给您开三天的药。</sub>
- **나**：네, 감사합니다. 약은 식후에 먹으면 되죠?  
  <sub>好的，谢谢。药饭后吃就行对吧？</sub>

### ③ 句型快反：症状描述 & 办事说明来意

> 描述症状：部位 + 이/가 + 症状 + 시간（-부터 계속）；说明来意：-(으)려고 왔는데요。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| 我头特别疼 | 머리가 너무 아파요. |
| 我对青霉素过敏 | 저 페니실린 알레르기 있어요. |
| 需要空腹来吗？ | 공복으로 와야 돼요? |
| 我想办一张借记卡 | 체크카드 만들고 싶어요. |
| 我想往中国汇款 | 중국으로 송금하고 싶은데요. |
| 结果什么时候出来？ | 결과는 언제 나와요? |

### ④ 独白任务（录音 60 秒）
