## 第 01 课　附和与反应　<small>맞장구와 리액션</small>

韩国人聊天时，听的人要不停地"接话"。不会反应 = 对话冷场。先学会接，才能聊得下去。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 아, 진짜요? | 啊，真的吗？ | 最万能的反应。语调上扬，"진짜"要说得有感情 |
| 2 | 헐, 대박. | 天哪，太夸张了／太厉害了 | 好事坏事都能用；对长辈少用"헐" |
| 3 | 아~ 그렇구나. | 啊～原来是这样 | 自言自语式，对长辈可以说"아, 그렇군요" |
| 4 | 맞아요, 맞아요. | 对对对 | 韩国人习惯重复两遍 |
| 5 | 그러니까요! | 就是说啊！（强烈同意） | 这里不是"所以"的意思！ |
| 6 | 에이, 설마요. | 哎，不会吧 |  |
| 7 | 와, 부럽다. | 哇，好羡慕 | 用原形"-다"表达当下感叹 |
| 8 | 어떡해요… | 这可怎么办啊（同情对方） | 读作[어떠캐요] |
| 9 | 진짜 다행이다. | 真是太好了（松了口气） |  |
| 10 | 그래서요? 어떻게 됐어요? | 然后呢？后来怎么样了？ | 让对方继续讲的神器 |

### ② 情景对话：同学智贤跟你讲她昨天面试的事

你扮演：**나**（两个角色都要练）

- **지현**：저 어제 면접 보고 왔어요.  
  <sub>我昨天去面试了。</sub>
- **나**：아, 진짜요? 어땠어요?  
  <sub>啊，真的吗？怎么样？</sub>
- **지현**：근데 면접관이 다섯 명이나 있었어요.  
  <sub>结果面试官竟然有五个人。</sub>
- **나**：헐, 대박. 엄청 떨렸겠다.  
  <sub>天哪，那肯定超紧张吧。</sub>
- **지현**：네, 그래서 첫 질문부터 머리가 하얘졌어요.  
  <sub>是啊，所以第一个问题脑子就一片空白了。</sub>
- **나**：어떡해요… 그래서요? 어떻게 됐어요?  
  <sub>天哪……然后呢？结果怎么样？</sub>
- **지현**：근데 오늘 아침에 합격했다고 연락 왔어요!  
  <sub>不过今天早上通知我说通过了！</sub>
- **나**：와, 진짜 다행이다! 축하해요!  
  <sub>哇，真是太好了！恭喜你！</sub>

### ③ 句型快反：听到消息 → 3秒内反应

> 反应慢是口语最大的破绽。看到情景，3秒内用韩语反应出来，不要先想中文。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| 朋友说他中了彩票 | 헐, 대박! 진짜요? |
| 朋友说钱包丢了 | 어떡해요… 괜찮아요? |
| 同事说下周去济州岛旅行 | 제주도요? 와, 좋겠다! 며칠 가요? |
| 朋友吐槽：这家店也太贵了吧 | 그러니까요! 너무 비싸요. |
| 朋友说他昨天在路上见到了IU本人 | 에이, 설마요. 진짜요? |
| 朋友讲到一半停住了 | 그래서요? 그다음에요? |

### ④ 独白任务（录音 60 秒）

假设朋友连续告诉你3个消息（一个好消息、一个坏消息、一个离谱的消息），你分别用至少两句话反应，并追问。要求中途停顿不超过3秒。

可用表达：`반응 + 질문 = 대화가 이어진다`　`진짜요? → 언제요? / 왜요? / 어떻게요?`　`헐 / 대박 / 어떡해 / 부럽다 / 다행이다`

## 第 02 课　口语句尾①：-거든요 / -잖아요 / -더라고요　<small>구어체 종결어미 1</small>

这三个句尾是"教科书韩语"和"真人韩语"的分水岭。TOPIK里你都认识，但你说话时几乎从来不用——这周起必须用。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 제가 요즘 좀 바쁘거든요. | 我最近有点忙（所以……） | -거든요：给出对方不知道的理由/背景 |
| 2 | 제가 원래 매운 걸 잘 못 먹거든요. | 我本来就不太能吃辣 |  |
| 3 | 어제 비 왔잖아요. | 昨天不是下雨了嘛 | -잖아요：提起对方也知道的事 |
| 4 | 아시잖아요, 저 길치인 거. | 您知道的嘛，我是路痴 |  |
| 5 | 거기 생각보다 비싸더라고요. | 那儿比想象的贵呢（我亲身体验到的） | -더라고요：回述亲身经历/观察 |
| 6 | 막상 해 보니까 재밌더라고요. | 真做起来发现还挺有意思的 |  |
| 7 | 한국 사람들 진짜 빨리 걷더라고요. | 韩国人走路真的好快（我观察到的） |  |
| 8 | 아니, 그게 아니라… | 不是，不是那个意思…… | 纠正误会的开头 |
| 9 | 그게 다가 아니에요. | 还不止这些呢 |  |
| 10 | 듣기는 괜찮은데 말하기가 어렵더라고요. | 听还行，但说起来就难了（我发现） |  |

### ② 情景对话：研究室前辈问你为什么昨天没来聚会

你扮演：**나**（两个角色都要练）

- **민수 선배**：어제 왜 안 왔어요? 다들 기다렸는데.  
  <sub>昨天怎么没来？大家都在等你。</sub>
- **나**：아, 죄송해요. 제가 어제 과제 마감이었거든요.  
  <sub>啊，抱歉。我昨天作业截止嘛。</sub>
- **민수 선배**：아, 그 과제? 그거 양 엄청 많잖아요.  
  <sub>啊，那个作业？那个量超大的嘛。</sub>
- **나**：네, 진짜 많더라고요. 새벽 세 시까지 했어요.  
  <sub>是啊，真的好多。我做到凌晨三点。</sub>
- **민수 선배**：헐, 고생했네요. 다 끝냈어요?  
  <sub>天哪，辛苦了。都做完了吗？</sub>
- **나**：네, 겨우요. 막상 끝내니까 뿌듯하더라고요.  
  <sub>嗯，好不容易。真做完了还挺有成就感的。</sub>
- **민수 선배**：다음 모임엔 꼭 와요. 고기 먹으러 갈 거거든요.  
  <sub>下次聚会一定要来啊。要去吃肉。</sub>
- **나**：좋아요! 저 고기 진짜 좋아하잖아요.  
  <sub>好啊！你知道我超爱吃肉的嘛。</sub>

### ③ 句型快反：-거든요 / -잖아요 / -더라고요 三选一

> 先判断：对方不知道的理由 → -거든요；对方也知道的事 → -잖아요；我亲身体验到的 → -더라고요

| 提示（5秒内开口） | 参考答案 |
|---|---|
| （解释迟到）今天地铁出故障了（对方不知道） | 오늘 지하철이 고장 났거든요. |
| （提醒）你上次不是说想去釜山嘛 | 저번에 부산 가고 싶다고 했잖아요. |
| （分享经历）去了那家店，发现人超多 | 그 가게 가 봤는데 사람 엄청 많더라고요. |
| （拒绝咖啡的理由）我晚上喝咖啡会睡不着 | 제가 밤에 커피 마시면 잠을 못 자거든요. |
| （安慰）你不是已经很努力了嘛 | 이미 충분히 열심히 했잖아요. |
| （感想）韩国冬天比想象中冷多了 | 한국 겨울이 생각보다 훨씬 춥더라고요. |

### ④ 独白任务（录音 90 秒）

讲讲"来韩国后（或接触韩国后）让我最意外的三件事"。-거든요、-잖아요、-더라고요 各至少用两次。

可用表达：`처음에는 몰랐는데 ~더라고요`　`중국에서는 원래 ~거든요`　`한국은 ~잖아요`

## 第 03 课　口语句尾②：-네요 / -는데요 / -(으)ㄹ걸요 / -나 봐요　<small>구어체 종결어미 2</small>

学会"感叹、委婉、推测、确认、邀请"的口语句尾，让你的话有语气、有温度。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 오늘 날씨 진짜 좋네요. | 今天天气真好啊 | -네요：当场发现的感叹 |
| 2 | 벌써 다 끝났네요. | 原来已经都结束了啊 |  |
| 3 | 저는 괜찮은데요? | 我觉得还好啊？（委婉表达不同看法） | -는데요 句尾上扬 = 轻微反驳 |
| 4 | 그건 좀 어려울 것 같은데요. | 那个恐怕有点难……（委婉拒绝） |  |
| 5 | 아마 지금 문 닫았을걸요. | 现在可能已经关门了吧 | -(으)ㄹ걸요：不太确定的推测，读[다다쓸껄료] |
| 6 | 이거 맞죠? | 这个是对的吧？ | -죠 = -지요，求确认 |
| 7 | 밖에 비 오나 봐요. | 外面好像在下雨（看到别人拿着伞） | -나 봐요：根据线索推测 |
| 8 | 다들 피곤한가 봐요. | 大家好像都累了 |  |
| 9 | 같이 갈래요? | 要一起去吗？ | -(으)ㄹ래요：问意愿，比 -(으)ㄹ까요 更随意 |
| 10 | 커피 한잔할래요? | 要不要喝杯咖啡？ |  |

### ② 情景对话：和同事秀珍一起下班走出大楼

你扮演：**나**（两个角色都要练）

- **나**：와, 밖에 바람 진짜 많이 부네요.  
  <sub>哇，外面风好大啊。</sub>
- **수진 씨**：그러게요. 사람들 우산 쓴 거 보니까 비도 오나 봐요.  
  <sub>是啊。看大家都打着伞，好像也在下雨。</sub>
- **나**：저 우산 없는데요…  
  <sub>我没带伞……</sub>
- **수진 씨**：편의점 가면 있을걸요. 저기 바로 앞에 있잖아요.  
  <sub>便利店应该有吧。不就在前面嘛。</sub>
- **나**：아, 맞다. 근데 수진 씨 집 이쪽 방향이죠?  
  <sub>啊，对哦。不过秀珍你家是这个方向吧？</sub>
- **수진 씨**：네, 맞아요. 같이 갈래요?  
  <sub>对呀。一起走吗？</sub>
- **나**：좋아요. 가는 길에 커피 한잔할래요? 제가 살게요.  
  <sub>好啊。路上喝杯咖啡吗？我请。</sub>
- **수진 씨**：오, 좋죠!  
  <sub>哦，好呀！</sub>

### ③ 句型快反：-네요 vs -나 봐요 vs -(으)ㄹ걸요 vs -죠 vs -(으)ㄹ래요

> -네요 = 我亲眼看到、当场感叹；-나 봐요 = 根据线索推测；-ㄹ걸요 = 我猜的（不负责）；-죠 = 确认；-ㄹ래요 = 问意愿

| 提示（5秒内开口） | 参考答案 |
|---|---|
| （尝了一口）这个真好吃啊 | 이거 진짜 맛있네요. |
| （看到同事一直打哈欠）他好像昨晚没睡好 | 어젯밤에 잠을 못 잤나 봐요. |
| （朋友问店开没开）现在可能还没开吧 | 아마 아직 안 열었을걸요. |
| （确认）明天是周五对吧？ | 내일 금요일이죠? |
| （邀请）周末要一起看电影吗？ | 주말에 같이 영화 볼래요? |
| （委婉反对）我觉得这个颜色还好啊？ | 저는 이 색깔 괜찮은데요? |

## 第 04 课　口语句尾③：-(으)ㄹ게요 / -(으)ㄹ래요 / -자 / -(으)ㄹ까요　<small>구어체 종결어미 3</small>

答应、表决心、问意愿、提议——这四个句尾每天要用几十次。用错了（比如对别人说"제가 할래요"）会很别扭。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 제가 할게요. | 我来做（答应对方/主动承担） | -(으)ㄹ게요：对听者做出承诺 |
| 2 | 이따가 연락할게요. | 待会儿联系你 |  |
| 3 | 저는 아이스 아메리카노 마실래요. | 我要喝冰美式（我的意愿） | -(으)ㄹ래요：说自己的意愿 |
| 4 | 같이 영화 볼래요? | 要一起看电影吗？（问对方意愿） |  |
| 5 | 우리 저녁 같이 먹을까요? | 我们一起吃晚饭好吗？（提议） | -(으)ㄹ까요：征求对方意见 |
| 6 | 제가 창문 열까요? | 要我开窗吗？（问对方需不需要） |  |
| 7 | 내일 같이 가자! | 明天一起去吧！ | -자：半语的提议 |
| 8 | 그럼 그렇게 할게요. | 那就这么办 |  |
| 9 | 다음부터 조심할게요. | 以后我会注意的 |  |
| 10 | 뭐 먹을래? 나는 아무거나 괜찮아. | 吃什么？我什么都行 |  |

### ② 情景对话：和同学一起准备发表

你扮演：**나**（两个角色都要练）

- **조원 민서**：발표 준비 어떻게 나눌까요?  
  <sub>发表的准备怎么分工？</sub>
- **나**：제가 PPT 만들게요. 디자인하는 거 좋아하거든요.  
  <sub>我来做PPT。我喜欢做设计。</sub>
- **조원 민서**：좋아요. 그럼 저는 자료 조사할게요.  
  <sub>好啊。那我来查资料。</sub>
- **나**：발표는 누가 할까요? 같이 반씩 할래요?  
  <sub>发表谁来？一起一人一半吗？</sub>
- **조원 민서**：네, 좋아요. 언제 한번 모여서 연습할까요?  
  <sub>好的。什么时候聚一下练习？</sub>
- **나**：목요일 저녁 어때요? 제가 스터디룸 예약할게요.  
  <sub>周四晚上怎么样？我来预约研讨室。</sub>
- **조원 민서**：완벽해요. 커피는 제가 살게요!  
  <sub>完美。咖啡我请！</sub>
- **나**：하하, 감사해요. 그럼 목요일에 봐요.  
  <sub>哈哈，谢谢。那周四见。</sub>

### ③ 句型快反：-(으)ㄹ게요（承诺）vs -(으)ㄹ래요（意愿）vs -(으)ㄹ까요（提议/询问）

> -ㄹ게요 是"我答应你我会做"，-ㄹ래요 是"我想做/你想做吗"，-ㄹ까요 是"……好吗/要我……吗"。主语是"我"并且是对听者的承诺时用 -ㄹ게요。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| （朋友问谁去买）我去买吧 | 제가 사 올게요. |
| （店员问喝什么）我要喝拿铁 | 저는 라떼 마실래요. |
| 要不要一起去散步？ | 같이 산책할래요? |
| 要我帮你拿吗？ | 제가 들어 드릴까요? |
| （半语提议）周末一起去汉江吧 | 주말에 같이 한강 가자. |
| 我会在明天之前发给你 | 내일까지 보내 드릴게요. |

### ④ 独白任务（录音 90 秒）

模拟和朋友商量一次周末活动：至少用 3 次 -(으)ㄹ까요（提议）、2 次 -(으)ㄹ래요（问意愿/说意愿）、3 次 -(으)ㄹ게요（分工承诺），最后用 -자 敲定。

可用表达：`우리 ~ㄹ까?`　`너는 뭐 ~ㄹ래?`　`그럼 내가 ~ㄹ게`　`좋아, ~자!`

## 第 05 课　缩略与填充词：让你说话"有人味"　<small>축약과 군말</small>

韩国人说话大量缩略（근데、그니까、뭘、난），还会用填充词（그냥、막、약간、뭐랄까）来争取思考时间。不会用这些，你就永远像在读课文。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 근데 그거 알아요? | 不过你知道那个吗？ | 그런데 → 근데，口语几乎只说"근데" |
| 2 | 그니까 제 말은요… | 所以我的意思是…… | 그러니까 → 그니까，用来重新解释 |
| 3 | 뭐랄까, 좀 애매해요. | 怎么说呢，有点微妙 | 想词的时候用，争取时间 |
| 4 | 약간 그런 느낌? | 有点那种感觉？ | 약간 在口语里常当"有点儿"的填充词 |
| 5 | 막 사람이 엄청 많았어요. | 就是人超级多 | 막：让描述更生动的填充词 |
| 6 | 그냥 집에서 쉬었어요. | 就在家休息了 |  |
| 7 | 이건 뭐예요? 그건 좀 아닌 것 같아요. | 这是什么？那个好像不太对 | 이것은 → 이건，그것은 → 그건 |
| 8 | 뭘 먹을지 모르겠어요. | 不知道吃什么好 | 무엇을 → 뭘 |
| 9 | 전 괜찮아요. 걱정 마세요. | 我没事，别担心 | 저는 → 전，걱정하지 마세요 → 걱정 마세요 |
| 10 | 잠깐만요, 생각 좀 해 볼게요. | 等一下，我想一想 |  |

### ② 情景对话：朋友夏俊问你周末过得怎么样

你扮演：**나**（两个角色都要练）

- **하준**：주말에 뭐 했어요?  
  <sub>周末干嘛了？</sub>
- **나**：음… 그냥 집에서 쉬었어요. 근데 일요일엔 홍대 갔다 왔어요.  
  <sub>嗯……就在家休息。不过周日去了趟弘大。</sub>
- **하준**：오, 홍대 어땠어요?  
  <sub>哦，弘大怎么样？</sub>
- **나**：막 사람이 엄청 많았어요. 약간 축제 같은 느낌?  
  <sub>人超级多。有点像庆典那种感觉？</sub>
- **하준**：아, 그때 무슨 행사 있었나 봐요.  
  <sub>啊，那时候好像有什么活动。</sub>
- **나**：그런가 봐요. 근데 뭘 먹을지 몰라서 한참 돌아다녔어요.  
  <sub>好像是。不过不知道吃什么，转了好久。</sub>
- **하준**：그럼 결국 뭐 먹었어요?  
  <sub>那最后吃了什么？</sub>
- **나**：뭐랄까… 그냥 편의점 라면 먹었어요. 하하.  
  <sub>怎么说呢……就吃了便利店泡面。哈哈。</sub>

### ③ 句型快反：书面形式 → 口语形式（秒转）

> 提示是"书面韩语"，你要立刻说出韩国人嘴上的说法。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| 그런데 그것은 무엇이에요? | 근데 그건 뭐예요? |
| 저는 무엇을 해야 할지 모르겠어요. | 전 뭘 해야 할지 모르겠어요. |
| 이것을 저에게 주세요. | 이거 저한테 주세요. |
| 그러니까 나는 그것을 몰랐어. | 그니까 난 그거 몰랐어. |
| 걱정하지 마세요. 저는 괜찮아요. | 걱정 마세요. 전 괜찮아요. |
| 무엇을 하고 있어요? 어디에 가요? | 뭐 하고 있어요? 어디 가요? |

### ④ 独白任务（录音 60 秒）

像跟朋友聊天一样讲讲你上周末做了什么。至少用4个填充词（그냥、막、약간、뭐랄까、근데），不许有"背诵感"。

可用表达：`그냥 ~했어요`　`근데 갑자기 ~`　`막 ~ 엄청 ~`　`약간 ~ 느낌?`
