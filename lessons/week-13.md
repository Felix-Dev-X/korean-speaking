## 第 61 课　倾听与共情　<small>공감하며 듣기</small>

韩国人聊烦恼时，最想听到的不是建议，而是"我懂你"。学会共情式的回应。

- **친구 지민**：내가 한 실수도 아닌데 팀장님이 다들 보는 앞에서 나한테 화냈어.

- **친구 지민**：응… 그래서 화장실 가서 좀 울었어.  
  <sub>嗯……所以我去厕所哭了一会儿。</sub>
- **나**：그런 일이 있었구나. 얘기해 줘서 고마워. 지금은 좀 괜찮아?

  <sub>跟你说完好多了。</sub>

  <sub>大家肯定都知道不是你的错。今天吃点好吃的好好休息吧。</sub>

### ③ 句型快反：共情三步：确认事实（-구나）→ 说出感受（-았/었겠다）→ 站在对方一边（나라도 ~）

> 先共情，别急着给建议。韩国人说"내 말 좀 들어 봐"时，往往只想被理解。

| 朋友说：和男朋友吵架了 | 싸웠구나. 마음이 많이 안 좋겠다. |
| 同事说：加班到凌晨 | 새벽까지요? 진짜 피곤하시겠어요. |
| 朋友说：被骗了钱 | 헐, 나라도 너무 화났을 것 같아. |
| 后辈说：想家了 | 그럴 수 있지. 가족 많이 보고 싶겠다. |
| （对方讲完）谢谢你跟我说 | 얘기해 줘서 고마워. |

  <sub>下次面试前跟我做一次模拟面试吧。我支持你！</sub>

### ③ 句型快反：笼统 → 具体（安慰与夸奖）

> "잘했어요"太笼统。好的夸奖 = 具体哪里好 + 你的感受。好的安慰 = 否定自责 + 肯定努力 + 提供帮助。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| （笼统）잘했어요 → 具体夸发表 | 발표 진짜 좋았어요. 특히 예시가 이해하기 쉬웠어요. |
| （笼统）요리 잘하네요 → 具体夸汤 | 이 찌개 간이 딱 맞아요. 어떻게 끓였어요? |
| 别太自责了，这不全是你的问题 | 너무 자책하지 마. 네 잘못만은 아니야. |
| 你已经尽力了 | 넌 최선을 다했어. |
| 需要帮忙随时说 | 도움이 필요하면 언제든지 말해. |
| 我相信你一定能做到 | 넌 분명히 해낼 거야. 난 믿어. |

## 第 63 课　给建议与烦恼咨询　<small>고민 상담</small>

被问"어떻게 해야 할까요?"时，能先问清情况、给出不同思路、再尊重对方的选择。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 무슨 고민 있어요? | 有什么烦恼吗？ |  |
| 2 | 혹시 어떤 점이 제일 걱정돼요? | 最担心的是哪一点？ |  |
| 3 | 제 생각을 말해도 될까요? | 我可以说说我的想法吗？ |  |
| 4 | 제가 너라면 일단 ~ 해 볼 것 같아. | 如果我是你，我会先试试…… |  |
| 5 | 두 가지 방법이 있을 것 같아요. | 好像有两种办法 |  |
| 6 | 장단점을 한번 적어 보는 건 어때요? | 把优缺点写下来看看怎么样？ |  |
| 7 | 너무 급하게 결정하지 않아도 돼. | 不用太着急决定 |  |
| 8 | 결국 선택은 네가 하는 거야. | 最终还是你自己选择 |  |

| 10 | 한번 부딪쳐 보는 것도 나쁘지 않아. | 去闯一闯也不坏 |  |

### ② 情景对话：后辈问你该不该转专业

你扮演：**나**（两个角色都要练）

- **후배 하윤**：선배, 저 전공을 바꿀지 고민이에요. 지금 전공이 저랑 안 맞는 것 같아서요.  
  <sub>前辈，我在纠结要不要换专业。感觉现在的专业不适合我。</sub>
- **나**：그렇구나. 혹시 어떤 점이 제일 안 맞는 것 같아?  
  <sub>这样啊。具体哪一点最不适合？</sub>
- **후배 하윤**：수업은 따라가는데, 하나도 재미가 없어요. 졸업하고 이 일 하는 게 상상이 안 돼요.  
  <sub>课能跟上，但一点意思都没有。想象不出毕业后做这个工作。</sub>
- **나**：음, 내 생각을 말해도 될까? 내가 너라면 일단 관심 있는 과 수업을 한두 개 들어 볼 것 같아.  
  <sub>嗯，我可以说说我的想法吗？如果我是你，会先去听一两门感兴趣的专业的课。</sub>
- **후배 하윤**：아, 바로 바꾸는 것보다요?  
  <sub>啊，比起直接换？</sub>
- **나**：응. 직접 들어 보면 진짜 맞는지 알 수 있잖아. 너무 급하게 결정하지 않아도 돼.  
  <sub>嗯。亲自听了才知道是不是真的适合嘛。不用太着急决定。</sub>
- **후배 하윤**：그 방법 좋네요. 그렇게 해 볼게요.  
  <sub>这个办法好。我就这么做。</sub>
- **나**：결국 선택은 네가 하는 거니까, 어떤 결정을 해도 난 응원할게.  
  <sub>最终还是你来选择，不管怎么决定我都支持你。</sub>

### ③ 句型快反：给建议的委婉梯度

> 从弱到强：-는 것도 방법이에요 → -는 게 어때요? → 제가 너라면 ~ 것 같아요 → -는 게 좋겠어요。对长辈和不熟的人用弱的。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| （弱）先休息几天也是个办法 | 며칠 쉬어 보는 것도 방법이에요. |
| （中）去找教授谈谈怎么样？ | 교수님이랑 한번 상담해 보는 게 어때요? |
| （中）如果我是你，我会先问问前辈 | 제가 너라면 선배한테 먼저 물어볼 것 같아. |
| （强）还是早点去医院比较好 | 빨리 병원에 가 보는 게 좋겠어요. |
| 你最担心的是什么？ | 제일 걱정되는 게 뭐예요? |
| 不管怎么选我都支持你 | 어떤 선택을 해도 응원할게. |

  <sub>好啊。在哪儿都要过得好。</sub>
- **나**：네, 선배도 건강 잘 챙기세요. 꼭 다시 만나요!  
  <sub>好的，前辈也照顾好身体。一定要再见！</sub>

### ③ 句型快反：感谢要具体：덕분에 + 具体的事 + 结果

> "감사합니다"只是开头。真正打动人的是具体回忆：你帮我做了什么、对我有什么影响。

| 提示（5秒内开口） | 参考答案 |

### ③ 句型快反：回应好消息三步：情绪（대박! 축하해!）→ 肯定努力（그럴 줄 알았어 / 고생한 보람）→ 追问细节 / 庆祝

> 别只说"축하해요"就结束。加一句肯定对方努力的话和一个追问，对方会感觉你真的为他高兴。
