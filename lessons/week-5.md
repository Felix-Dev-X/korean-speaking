## 第 24 课　打电话　<small>전화 통화</small>

电话没有表情和手势，是口语的"高难度模式"。固定开头、确认信息、礼貌结束，这三块必须熟练。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 여보세요? 리웨이 씨 핸드폰 맞죠? | 喂？是李伟的手机吧？ |  |
| 2 | 잠시만요, 잘 안 들려요. | 稍等，听不太清 |  |
| 3 | 다시 한번 말씀해 주시겠어요? | 能再说一遍吗？ |  |
| 4 | 예약 변경하려고 전화드렸는데요. | 我打电话是想改预约 |  |
| 5 | 성함이 어떻게 되세요? | 请问您叫什么名字？ | 一定要听懂 |
| 6 | 전화번호 뒷자리 네 개만 말씀해 주세요. | 请告诉我电话号码后四位 |  |
| 7 | 문자로 보내 주실 수 있어요? | 能发短信给我吗？ |  |
| 8 | 지금 통화 괜찮아요? | 现在方便通话吗？ |  |
| 9 | 나중에 다시 전화드릴게요. | 我稍后再打给您 |  |
| 10 | 네, 들어가세요. | 好的，再见（挂电话时） | 电话结束的固定说法 |

### ② 情景对话：打电话给美发店改预约

你扮演：**나**（两个角色都要练）

- **나**：여보세요? 거기 헤어살롱 맞죠?  
  <sub>喂？是美发沙龙吧？</sub>
- **미용실 직원**：네, 맞습니다. 무엇을 도와드릴까요?  
  <sub>是的。有什么可以帮您？</sub>
- **나**：내일 오후 세 시에 커트 예약했는데요, 시간 좀 변경하려고 전화드렸어요.  
  <sub>我预约了明天下午三点剪发，打电话想改一下时间。</sub>
- **미용실 직원**：네, 성함이 어떻게 되세요?  
  <sub>好的，请问您叫什么名字？</sub>
- **나**：리웨이요. 전화번호 뒷자리는 5678이에요.  
  <sub>李伟。电话后四位是5678。</sub>
- **미용실 직원**：확인됐습니다. 언제로 바꿔 드릴까요?  
  <sub>确认了。要改到什么时候？</sub>
- **나**：혹시 모레 같은 시간 돼요?  
  <sub>后天同一时间可以吗？</sub>
- **미용실 직원**：네, 가능합니다. 예약 문자 다시 보내 드릴게요.  
  <sub>可以的。我再给您发预约短信。</sub>
- **나**：네, 감사합니다. 들어가세요.  
  <sub>好的，谢谢。再见。</sub>

### ④ 独白任务（录音 60 秒）

电话预约餐厅：人数、日期时间、要包间、有人不吃辣/有过敏，问能不能停车，最后确认信息并礼貌结束通话。

可用表达：`~ 예약하려고 전화드렸는데요`　`혹시 룸 있어요?`　`한 명이 매운 걸 못 먹어서요`　`주차 돼요?`　`네, 감사합니다. 수고하세요`

## 第 25 课　请假、迟到、早退的报告　<small>근태 보고하기</small>

在学校和公司，"报告自己的状况"是每周都会用到的：迟到怎么说、请假怎么说、早退怎么说，既要礼貌又要说清理由和后续安排。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 죄송한데, 오늘 10분 정도 늦을 것 같습니다. | 抱歉，今天可能要晚到10分钟左右 |  |
| 2 | 지하철이 지연돼서요. | 因为地铁晚点了 |  |
| 3 | 몸이 안 좋아서 오늘 하루 쉬어도 될까요? | 身体不舒服，今天可以请一天假吗？ |  |
| 4 | 병원에 들렀다가 오후에 출근하겠습니다. | 去趟医院，下午来上班 |  |
| 5 | 급한 일이 생겨서 오늘 조금 일찍 들어가 봐도 될까요? | 有急事，今天能稍微早点走吗？ |  |
| 6 | 오늘 할 일은 내일 오전까지 마무리하겠습니다. | 今天的工作我明天上午前完成 |  |
| 7 | 다음 주 금요일에 연차를 쓰고 싶습니다. | 下周五想请年假 |  |
| 8 | 수업에 결석해서 죄송합니다. 과제는 어떻게 하면 될까요? | 缺课很抱歉。作业要怎么交？ |  |
| 9 | 진단서 제출하겠습니다. | 我会提交诊断书 |  |
| 10 | 미리 말씀드리지 못해서 죄송합니다. | 没能提前跟您说，很抱歉 |  |

### ② 情景对话：早上打电话给组长请病假

你扮演：**나**（两个角色都要练）

- **나**：팀장님, 아침 일찍 죄송합니다. 리웨이입니다.  
  <sub>组长，一大早打扰您很抱歉。我是李伟。</sub>
- **팀장님**：네, 무슨 일이에요?  
  <sub>嗯，什么事？</sub>
- **나**：어젯밤부터 열이 많이 나서, 오늘 하루 쉬어도 될까요?  
  <sub>从昨晚开始发高烧，今天可以请一天假吗？</sub>
- **팀장님**：아이고, 많이 아파요? 병원은 갔어요?  
  <sub>哎呀，很严重吗？去医院了吗？</sub>
- **나**：오전에 가 보려고요. 오늘 회의 자료는 메일로 먼저 보내 드렸습니다.  
  <sub>打算上午去。今天的会议资料我已经先发邮件给您了。</sub>
- **팀장님**：고마워요. 일 걱정하지 말고 푹 쉬어요.  
  <sub>谢谢。别担心工作，好好休息。</sub>
- **나**：감사합니다. 진단서는 내일 제출하겠습니다. 급한 일 있으시면 문자 주세요.  
  <sub>谢谢您。诊断书明天提交。有急事请给我发短信。</sub>
- **팀장님**：알겠어요. 몸조리 잘해요.  
  <sub>知道了。好好养病。</sub>

### ③ 句型快反：报告三要素：情况（-(으)ㄹ 것 같습니다）+ 理由（-아/어서요）+ 后续安排（-겠습니다）

> 先道歉、再说情况和理由、最后一定要说"后续怎么处理"，这样上司最放心。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| 我可能会晚到20分钟，因为堵车 | 차가 막혀서 20분 정도 늦을 것 같습니다. |
| 家里有急事，能早退吗？ | 집에 급한 일이 생겨서 조금 일찍 가 봐도 될까요? |
| 我会在家处理工作 | 업무는 집에서 처리하겠습니다. |
| 明天上午我想请半天假 | 내일 오전에 반차를 쓰고 싶습니다. |
| 今天的课我没法去了，能把资料发给我吗？ | 오늘 수업에 못 갈 것 같은데, 자료 좀 보내 주실 수 있을까요? |
| 给您添麻烦了，抱歉 | 번거롭게 해 드려서 죄송합니다. |

### ④ 独白任务（录音 2 分钟）

三段电话：① 早上地铁故障要迟到，打给上司 ② 下午家里有急事要早退，当面跟上司说 ③ 生病缺课，给教授说明情况并问作业。每段都要有：道歉 + 情况 + 理由 + 后续安排。

可用表达：`죄송한데, ~ 것 같습니다`　`~아서요`　`~ 해도 될까요?`　`~는 ~까지 하겠습니다`　`미리 말씀드리지 못해서 죄송합니다`
