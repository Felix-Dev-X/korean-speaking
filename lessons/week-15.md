## 第 75 课　天气、季节与穿衣　<small>날씨와 옷차림</small>

天气是韩国人最常聊的"万能话题"，也和穿衣、生活紧密相关：换季、梅雨、雾霾、寒流、穿什么出门。

### ① 核心句块（每句跟读 3 遍，再遮住韩语看中文说）

| # | 韩语 | 中文 | 要点 |
|---|---|---|---|
| 1 | 요즘 일교차가 커서 감기 걸리기 쉬워요. | 最近昼夜温差大，容易感冒 |  |
| 2 | 아침저녁으로는 쌀쌀하니까 겉옷 챙기세요. | 早晚有点凉，带件外套 |  |
| 3 | 한파 주의보가 내렸대요. | 听说发布了寒潮预警 |  |
| 4 | 오늘 체감 온도가 영하 15도래요. | 听说今天体感温度零下15度 |  |
| 5 | 패딩 없이는 못 나가요. | 没羽绒服出不了门 |  |
| 6 | 장마라서 습해서 빨래가 안 말라요. | 梅雨季太潮了，衣服晾不干 |  |
| 7 | 오늘 미세먼지 나쁨이래요. 마스크 꼭 쓰세요. | 听说今天细颗粒物"差"，一定戴口罩 |  |
| 8 | 반팔 입기에는 아직 좀 추워요. | 穿短袖还有点冷 |  |

### ② 情景对话：早上出门前和室友聊天气

你扮演：**나**（两个角色都要练）

- **룸메이트 지호**：오늘 날씨 봤어? 한파 주의보래.  
  <sub>看今天天气了吗？说有寒潮预警。</sub>
- **나**：헐, 진짜? 어제까지는 별로 안 추웠는데.  
  <sub>天哪，真的？到昨天为止还不怎么冷呢。</sub>
- **룸메이트 지호**：체감 온도가 영하 15도래. 패딩 꼭 입고 나가.  
  <sub>说体感零下15度。一定要穿羽绒服出门。</sub>
- **나**：나 롱패딩 없는데… 그냥 코트 입으면 안 될까?  
  <sub>我没有长款羽绒服……穿大衣不行吗？</sub>
- **룸메이트 지호**：코트로는 안 돼. 안에 히트텍이라도 입고, 목도리랑 장갑도 챙겨.  
  <sub>大衣不行。里面至少穿件保暖内衣，围巾手套也带上。</sub>
- **나**：알겠어. 겹겹이 입을게. 중국 남쪽은 이렇게 안 추운데.  
  <sub>知道了。我多穿几层。中国南方没这么冷。</sub>
- **룸메이트 지호**：한국 겨울은 바람이 진짜 매서워. 이번 주말에 같이 롱패딩 사러 가자.  
  <sub>韩国冬天风真的很刺骨。这周末一起去买长款羽绒服吧。</sub>
- **나**：좋아! 핫팩도 좀 사야겠다.  
  <sub>好啊！暖宝宝也得买点。</sub>

### ③ 句型快反：天气 + 建议：-(으)니까 -(으)세요 / -기에는 / -래요（转述天气预报）

> 天气预报常用转述：비 온대요、춥대요、미세먼지 나쁨이래요。建议用：-(으)니까 ~ 챙기세요。

| 提示（5秒内开口） | 参考答案 |
|---|---|
| 听说明天下大雪 | 내일 눈이 많이 온대요. |
| 今天很热，多喝水 | 오늘 더우니까 물 많이 드세요. |
| 穿大衣还有点热 | 코트 입기에는 좀 더워요. |
| 最近换季，注意别感冒 | 요즘 환절기니까 감기 조심하세요. |
| 湿度太高了，好闷 | 습도가 너무 높아서 꿉꿉해요. |
| 今天适合出去玩 | 오늘 놀러 가기 딱 좋은 날씨네요. |
